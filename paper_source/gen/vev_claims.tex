Any two members share $x_1$, so the family is pairwise intersecting. For each $k \ge 1$, $T_k = \{y_1, \dots, y_{k-1}, x_k\}$ meets $F_n$ through $y_n$ when $n < k$ and through $x_k$ when $n \ge k$, so it is a finite transversal; removing $y_i$ misses $F_i$ and removing $x_k$ misses $F_k$, so it is inclusion-minimal. The $T_k$ are pairwise distinct, so there are infinitely many. \emph{Invalid counterexample offered:} Take $F_n = \{x_n\}$ for $n \ge 1$ with distinct symbols $x_n$. Then each $T_k = \{x_k\}$ is a minimal finite transversal, so there are infinitely many.
