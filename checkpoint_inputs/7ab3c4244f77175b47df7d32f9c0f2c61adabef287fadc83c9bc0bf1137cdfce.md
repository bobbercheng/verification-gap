# Status
partial — strong numerical conjecture with a verified auxiliary lemma, but no
rigorous proof written or reviewed. The conjectured answer c(n) = 2^n/(2^{n+1}-1)
is supported by a verified lower-bound strategy and numerically-converged bounds
for n = 1..5, and the competing conjecture (n+1)/(2n+1) has been refuted. No

# Task
IMO 2026 Problem 3. Liu marks ≤ n points on a stick of length 1, then Xiang marks
≤ n distinct points. The stick is cut at all marked points; players then alternate
claiming any unclaimed piece, Liu first, each maximising their own total length.
For each positive integer n, determine the largest c such that Liu can guarantee a
total length ≥ c regardless of Xiang's play. (Equivalently,
c(n) = max_A min_B Liu_take(A,B).)

# Approaches tried
1. Reduction to a draft (claim) game. After both players mark, the cutting is fixed
   and only the alternating claim phase matters. Proved-by-verification lemma:
   under optimal claim play with Liu moving first, Liu's guaranteed total equals
   the odd-rank sum of the pieces sorted descending (largest + 3rd-largest + ...).
   Verified 2000/2000 against exact minimax (explore.py / claim_bruteforce). This
   is rigorous (provable by a simple greedy exchange / induction argument) and
   collapses the game to: c(n) = max_A min_B [odd-rank sum of pieces from (A,B)].

2. Numerical min/max solvers for the reduced game (explore.py, explore2.py,
   explore3.py, opt2.py, refine.py, n2.py, n2b.py). Inner solver: Xiang minimises
   Liu's odd-rank sum over 0..n cuts via multistart Nelder-Mead + differential
   evolution + full grid combination (n2.py/n2b.py). Outer solver: Liu maximises
   the inner value via grid + coordinate ascent + multistart.

3. Conjecture c(n) = (n+1)/(2n+1) with candidate strategy A = {1,3,...,2n-1}/(2n+1)
   (conjecture.py, conj2.py, conj3.py). REFUTED: for n ≥ 2 the candidate strategy
   only yields Liu-take = 0.5 under Xiang's best response, and random/grid maximima
   fall well below (n+1)/(2n+1) (e.g. n=2 random max 0.559 < 0.6; n=3 0.523 < 0.571).

4. Conjecture c(n) = 2^n/(2^{n+1}-1) with geometric Liu strategy producing piece
   sizes in ratio 2^n : 2^{n-1} : ... : 2 : 1 (verify.py). This is the surviving
   and much better-supported conjecture.

# Current best
Conjectured answer (numerically established, not proven):
  c(n) = 2^n / (2^{n+1} - 1).

Decisive numerical evidence recovered:
- Lower bound (Liu strategy): the geometric configuration (Liu marks so the pieces
  are proportional to 2^n, 2^{n-1}, ..., 2, 1, largest leftmost) yields Liu-take
  exactly 2^n/(2^{n+1}-1) against Xiang's best response, for n = 1..5, to machine
  precision (diff ≤ 1e-15). E.g. n=2: A = [4/7, 6/7], Xiang best B = [2/7],
  Liu-take = 4/7 = 0.571429.
- Upper bound (Xiang cap), n=2 maximisation: grid + coordinate ascent maximising
  Liu's guarantee over all A converges to 0.5714 = 4/7, attained at piece ratio
  4:2:1 (a≈0.5718, b≈0.2869, c≈0.1412). No Liu configuration for n = 1..5 was
  found that exceeds 2^n/(2^{n+1}-1) under Xiang's best response.
- Values: c(1)=2/3, c(2)=4/7≈0.5714, c(3)=8/15≈0.5333, c(4)=16/31≈0.5161,
  c(5)=32/63≈0.5079; c(n) → 1/2 as n → ∞.

# Full result
Not yet complete. What is actually established:
- (Rigorous, by verification of a provable lemma) The claim/draft game value:
  Liu's optimal-play total = sum of pieces at odd ranks (1st, 3rd, 5th, ...) when
  pieces are sorted descending. This reduces the original game to
  c(n) = max_A min_B [odd-rank sum].
- (Numerical, not proof) c(n) = 2^n/(2^{n+1}-1) for n = 1..5: the geometric Liu
  strategy attains it (lower bound) and no configuration beats it (upper bound),
  via grid + multistart local/global optimisation.
- (Numerical refutation) c(n) = (n+1)/(2n+1) is too large for n ≥ 2.

No closed-form proof has been written; candidates/ and reviews/ are empty.

# Open gaps
- No rigorous proof of the lower bound: that the geometric Liu strategy guarantees
  2^n/(2^{n+1}-1) for general n (only verified n ≤ 5 numerically).
- No rigorous proof of the upper bound: that for every A, Xiang can hold Liu to
  ≤ 2^n/(2^{n+1}-1). Currently only checked by random/grid search for n ≤ 5; no
  argument at all for n ≥ 6.
- The claim-game lemma is verified and provable but has not been written up as a
  formal proof; the inductive/exchange argument needs to be recorded.
- No formal proof artifact exists (candidates/ empty) and none has been reviewed
  (reviews/ empty). The entire result is currently numerical evidence plus one
  verified auxiliary lemma.
- Structural question open: is the geometric ratio 2^n:...:1 provably Liu's unique
  optimal strategy, and what is Xiang's matching optimal response in closed form
  (numerics suggest Xiang halves each of Liu's largest pieces)?
