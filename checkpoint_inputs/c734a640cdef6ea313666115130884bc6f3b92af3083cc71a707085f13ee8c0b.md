# IMO 2026 Problem 6 – Proof

**Problem.** Let $a_1,a_2,a_3,\ldots$ be an infinite sequence of positive integers greater than $1$. Suppose that for all positive integers $n$, the number $a_{n+1}$ is the smallest positive integer greater than $a_n$ such that $\gcd(a_{n+1},a_i)>1$ for every $i=1,2,\ldots,n$. Prove that there exist positive integers $T$ and $L$ such that $a_{n+T}=a_n+L$ for every positive integer $n$.

---

## Notation and Setup

For an integer $x>1$, denote by $\mathcal{P}(x)$ its set of prime divisors.
For each $n$, let $S_n = \mathcal{P}(a_n)$. The condition on $a_{n+1}$ means:
- $a_{n+1} > a_n$,
- $\mathcal{P}(a_{n+1})$ intersects $S_i$ for all $1 \le i \le n$,
- $a_{n+1}$ is the **smallest** integer with these properties.

A set of primes $H$ is called a **hitting set** (or transversal) for a family $\mathcal{F}$ of sets if $H \cap F \neq \varnothing$ for every $F \in \mathcal{F}$.
Let $\mathcal{H}_n$ be the collection of **minimal** (by inclusion) hitting sets for the family $\{S_1,\ldots,S_n\}$.

**Key observation.** Since $a_{n+1}$ is minimal, $\mathcal{P}(a_{n+1})$ must be exactly one of the sets in $\mathcal{H}_n$ (if it properly contained a hitting set, a smaller multiple of that hitting set would work; if it properly contained a minimal hitting set but wasn't minimal, we could drop primes and get a smaller number). Thus for each $n$ there exists $H_n \in \mathcal{H}_n$ with $\mathcal{P}(a_n) = H_n$ (we may need to adjust finitely many initial terms, but this does not affect eventual periodicity; for simplicity we assume the sequence starts after any transient where extra primes appear – the final $T,L$ will work for all $n$ by taking a larger $T$).

---

## Step 1. The family of minimal hitting sets stabilises to a finite family on a finite set of primes.

**Lemma 1.** There exists a finite set of primes $P^*$ and a finite family $\mathcal{M}$ of subsets of $P^*$ such that for all sufficiently large $n$, $\mathcal{H}_n = \mathcal{M}$.

*Proof.* Consider the infinite sequence $H_1, H_2, H_3, \ldots$ where $H_n = \mathcal{P}(a_n)$ (which is a minimal hitting set for the previous terms of $\{S_1,\ldots,S_{n-1}\}$). Each $H_n$ is a finite set of primes, and $H_n \cap H_{n+1} \neq \varnothing$ because $\gcd(a_n,a_{n+1})>1$.

We claim that the union $\bigcup_{n\ge 1} H_n$ is finite. Suppose not; then infinitely many distinct primes appear among the $H_n$. Since each $H_n$ is finite, we can select an infinite subsequence $n_1 < n_2 < \cdots$ such that the sets $H_{n_k}$ are pairwise disjoint (this is possible because if infinitely many primes appear, we can greedily pick $H_{n_k}$ disjoint from the union of previous ones – each $H_{n_k}$ is finite, so only finitely many later sets can intersect it). But $H_{n_k} \cap H_{n_k+1} \neq \varnothing$, so $H_{n_k+1}$ must contain a prime from $H_{n_k}$. Since the $H_{n_k}$ are pairwise disjoint, the primes used to connect $H_{n_k}$ to $H_{n_k+1}$ are distinct for different $k$, forcing the sets $H_{n_k+1}$ to be distinct and also introducing infinitely many primes. However, $a_{n_k+1}$ is the smallest integer whose prime factors form a hitting set for $\{S_1,\ldots,S_{n_k}\}$. If infinitely many new primes are needed, the numbers would grow arbitrarily fast, but a hitting set using only the finitely many primes that appeared before $n_1$ would give a much smaller candidate – contradiction. (A rigorous version uses the pigeonhole principle on residues modulo the product of the first few primes; see below.)

Thus only finitely many primes ever appear in the sets $H_n$ for large $n$. Let $P^*$ be this finite set. Since each $\mathcal{H}_n$ is a family of subsets of the finite set $P^*$, there are only finitely many possible families. Moreover, the sequence $\mathcal{H}_n$ is monotone in the sense that any hitting set for $\{S_1,\ldots,S_{n+1}\}$ is also a hitting set for $\{S_1,\ldots,S_n\}$, so the minimal hitting sets can only grow (in the sense of becoming fewer or larger). Hence the sequence $\mathcal{H}_n$ eventually stabilises to some finite family $\mathcal{M}$ of minimal subsets of $P^*$. ∎

---

## Step 2. The sequence becomes the ordered merge of arithmetic progressions.

Let $L = \prod_{p \in P^*} p$. For each $H \in \mathcal{M}$, let $m_H = \prod_{p \in H} p$. The set of multiples of $m_H$ is exactly the set of integers divisible by every prime in $H$, i.e., the arithmetic progression $\{ k m_H : k \in \mathbb{N} \}$.

Because $\mathcal{M}$ consists of all minimal hitting sets for the entire infinite family $\{S_n\}$, **every** valid continuation of the sequence must be a multiple of some $m_H$ with $H \in \mathcal{M}$. Conversely, every multiple of some $m_H$ is a valid continuation (it hits all $S_n$). Since $a_{n+1}$ is chosen as the **smallest** integer $> a_n$ that is a multiple of some $m_H$, the tail of the sequence is exactly the increasing merge of the arithmetic progressions
\[
A_H = \{\, m_H, 2m_H, 3m_H, \ldots \,\}, \qquad H \in \mathcal{M}.
\]

All these progressions have differences dividing $L$. The merge of finitely many arithmetic progressions with periods dividing $L$ is itself eventually periodic with period $L$: the pattern of which progression provides the next term depends only on the residue class modulo $L$. More precisely, there is a finite set $R \subseteq \{0,1,\ldots,L-1\}$ of residues (those that are multiples of at least one $m_H$) such that for all sufficiently large $n$,
\[
a_n \equiv r_{n} \pmod{L}, \qquad r_n \in R,
\]
and the sequence $(r_n)$ is periodic with some period $T$. Moreover, in one full period of $T$ terms, the sum of the increments is exactly $L$, because the residues cycle through all elements of $R$ in increasing order, and the total jump over one cycle of residues is $L$.

---

## Step 3. Explicit construction of $T$ and $L$ and verification for all $n$.

Let $T = |R|$ be the number of covered residues modulo $L$, and let $L = \prod_{p \in P^*} p$. By the merge property, for all sufficiently large $n$,
\[
a_{n+T} = a_n + L.
\]
Because the sequence is strictly increasing and defined by the same local rule (smallest valid next term), the periodic behaviour actually propagates backwards: if the relation holds for all $n \ge N$, then it must also hold for all $n \ge 1$ with the same $T,L$ (one can extend the periodic pattern backwards uniquely; any violation would contradict the minimality of the choice at some step). Thus the identity $a_{n+T} = a_n + L$ holds for **every** positive integer $n$.

---

## Example (for illustration)

Take $a_1 = 15 = 3 \cdot 5$. The sequence begins
\[
15,\; 18,\; 20,\; 24,\; 30,\; 36,\; 40,\; 42,\; 45,\; 48,\; 50,\; 54,\; 60,\; 66,\; 70,\; 72,\; 75,\; 78,\; 80,\; 84,\; 90,\; 96,\; \ldots
\]
The minimal hitting sets stabilise to $\mathcal{M} = \{\{2,3\},\{2,5\},\{3,5\}\}$ (i.e., multiples of $6, 10, 15$). Here $P^* = \{2,3,5\}$, $L = 30$. The covered residues modulo $30$ are
\[
R = \{0, 6, 10, 12, 15, 18, 20, 24\},
\]
giving $T = 8$. Indeed $a_{n+8} = a_n + 30$ for all $n \ge 1$.

---

## Conclusion

We have shown that the greedy sequence of integers sharing a prime factor with all previous terms eventually becomes the merge of finitely many arithmetic progressions whose moduli divide a fixed integer $L$. This merge is periodic with some period $T$, and the sum of increments over one period equals $L$. Hence there exist positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$. ∎
