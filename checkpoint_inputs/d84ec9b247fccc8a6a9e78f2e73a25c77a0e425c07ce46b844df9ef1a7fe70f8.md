# Task
IMO 2026 Problem 3. A stick is the closed interval [0,1]. Liu marks at most n
points on the stick, then Xiang marks at most n points; all marked points (Liu's
and Xiang's together) are distinct. "At most n" includes 0 (a player may pass);
"on the stick" includes the endpoints 0 and 1 (a mark at an endpoint is a legal
but degenerate cut that produces a 0-length piece and is dominated by either
passing or marking an interior point). The stick is then cut at all marked points;
players alternate claiming any unclaimed piece, Liu first, each maximising their
own total length. For each positive integer n, determine the largest c such that
Liu can guarantee total length ≥ c regardless of Xiang's play.

Game value (definition only — see (B)/(B′) for sup/inf vs max/min): the largest
total Liu can force is the supremum over Liu configurations A of the infimum
over legal Xiang responses B of Liu's optimal-claim total O(A,B).

# Approaches tried
1. Reduction to a draft (claim) game — DEDUCTIVE. After A,B are placed the cutting
   is fixed; only the alternating claim phase matters. Lemma (proved, §Full result
   (A)): Liu's claim-game value = odd-rank sum of the pieces sorted descending.
   This collapses the claim phase to a number O(A,B).

2. The geometric Liu configuration and the halving Xiang response (exact,
   §Full result (D)). Liu places points so his own segments are 2^n, 2^{n−1}, …,
   2, 1 (largest first), normalised by D = 2^{n+1}−1. Xiang's halving response:
   cut each of the first n Liu segments at its midpoint. The piece multiset is,
   in units of 1/D, exactly {2^{n−1},2^{n−1}, 2^{n−2},2^{n−2}, …, 2,2, 1,1,1};
   its odd-rank sum is exactly 2^n (exact arithmetic), i.e. the Liu-take of THIS
   pair is 2^n/D. Scripts: verify_exact.py (exact rationals), verify.py/opt2.py
   (float). NOTE (D5): this is a matched pair realising the number 2^n/D, NOT an
   equilibrium and NOT a proof that 2^n/D is the value.

3. Exact-grid minimisation over Xiang (evidence for the lower-bound side only;
   cannot prove LB — D1). For the geometric Liu config, minimise O over Xiang cut
   sets on a rational grid (fractions.Fraction, exact): n=2 min = 4/7 exactly,
   n=3 min = 8/15 exactly (the grid hits the halving midpoints); n=4,5 the grid
   min lies just ABOVE 2^n/D because the midpoints (multiples of 1/31, 1/63) are
   off-grid. Nothing on the grid beats 2^n/D. Consistent with halving being
   optimal, but a finite grid cannot prove a "for every continuum marking"
   statement (D1).

4. Floating-point search (evidence only; cannot certify extrema — D1/D2):
   opt2.py / verify.py / conjecture.py search Liu–Xiang via Nelder–Mead with
   structured seeds. They never find a Xiang response below 2^n/D against the
   geometric config, nor a Liu config above 2^n/D, for n ≤ 5. These are
   local-optimisation heuristics with no global certificate; they are evidence,
   not proof.

5. Conjecture c(n)=(n+1)/(2n+1) — numerically refuted for n ≥ 2 (evidence only):
   the candidate strategy yields only 0.5 at n=2 and random/grid maxima fall below
   (n+1)/(2n+1) (e.g. n=2 ≈ 0.559 < 0.6). Kept only as a ruled-out alternative.

# Full result
Not complete. The case n = 1 is fully solved (value + both directions +
attainment). For n ≥ 2 the value is not determined. What is rigorously established:

(A) Draft-game lemma (DEDUCTIVE).
    Let pieces p_1 ≥ p_2 ≥ … ≥ p_m be fixed. Liu and Xiang alternate claiming one
    piece each, Liu first; both maximise their own total. Then Liu's value (under
    optimal play by both) is the odd-rank sum S_odd = p_1 + p_3 + p_5 + … .

    Proof.
    (Liu guarantees ≥ S_odd.) Liu's strategy: always take a largest remaining
    piece. Before Liu's k-th turn exactly 2(k−1) pieces are gone. The pieces that
    are ≥ p_{2k−1} are precisely p_1,…,p_{2k−1} (2k−1 of them); they cannot all be
    gone, since only 2k−2 < 2k−1 are. Hence some piece ≥ p_{2k−1} survives, so
    Liu's k-th pick is ≥ p_{2k−1}. Summing over Liu's turns gives Liu ≥ S_odd.
    (Xiang holds Liu to ≤ S_odd.) Xiang's strategy: always take a largest
    remaining piece. Before Xiang's k-th turn, 2k−1 pieces are gone, so among
    p_1,…,p_{2k} at least one survives; Xiang's k-th pick is ≥ p_{2k}. Summing,
    Xiang ≥ p_2+p_4+… = S_even. Since S_odd + S_even = total, Liu ≤ S_odd.
    Together, the value is exactly S_odd. ∎

(B) Exact reduction, with sup/inf.
    By (A), once A,B are fixed, Liu's optimal-claim total is O(A,B), the odd-rank
    sum of the pieces of [0,1]\(A∪B). Therefore the largest total Liu can force is
        c(n) = sup_{A,|A|≤n}  inf_{B,|B|≤n, A∩B=∅}  O(A,B).                (R)
    We write sup/inf, not max/min. Reason: the Liu domain is a union (over
    |A|=0,1,…,n) of open configuration spaces of distinct points in (0,1), and the
    Xiang domain additionally excludes the finitely many points of A; these are
    not compact, so an extremum need not be attained. Writing max/min is justified
    only after an explicit two-sided proof: a lower-bound witness A_0 with
    inf_B O(A_0,B) ≥ v (attainment of the sup) AND an upper bound
    inf_B O(A,B) ≤ v for every A. The finite exclusion A∩B=∅ is harmless for
    infima (Xiang may always approximate a forbidden point), and endpoint marks
    only create 0-length pieces, so restricting attention to interior marks loses
    nothing.

(B′) The supremum sup_A inf_B O(A,B) is the answer to "largest c Liu can
     guarantee" WITHOUT any attainment assumption (addresses D2).
     Define the guaranteeable set
        G(n) = { c ∈ ℝ : ∃ A (|A|≤n), ∀ B (|B|≤n, A∩B=∅), O(A,B) ≥ c }.
     "Liu may guarantee ≥ c" means exactly c ∈ G(n). For fixed A the admissible c
     are {c : c ≤ inf_B O(A,B)} = (−∞, inf_B O(A,B)]. Hence
        G(n) = ⋃_A (−∞, inf_B O(A,B)],
     whose supremum is sup_A inf_B O(A,B) REGARDLESS of whether that supremum is
     attained: if it is attained by some A_0 then G(n) = (−∞, c(n)] and the
     maximum is c(n); if not then G(n) = (−∞, c(n)) and there is no maximum, only
     the supremum c(n). In both cases the task's "largest value c such that Liu
     may guarantee ≥ c", read as a least upper bound, is c(n) = sup_A inf_B O(A,B).
     So the equivalence challenged in D2 — "largest guaranteed value =
     sup_A inf_B O(A,B)" — is justified at the supremum level with no attainment
     hypothesis. What attainment adds is the STRONGER statement that some A_0
     actually realises c(n) (so Liu guarantees exactly c(n), not merely every
     value strictly below it). That stronger statement is proved for n = 1
     (A_0 = {2/3}, see (C)) and is OPEN for n ≥ 2; for n ≥ 2 it is also MOOT
     until c(n) is itself determined, which is the open lower/upper-bound gap D1.
     Thus D2 separates cleanly into (i) sup-identification — proved; (ii)
     attainment — proved n=1, open n≥2.

(C) c(1) = 2/3 (both directions; all legal cases; attainment — fully solves n=1).
    Lower bound (Liu can force 2/3). Liu marks the single interior point 2/3,
    giving pieces [0,2/3] and [2/3,1], i.e. {2/3, 1/3}. Xiang marks ≤ 1 point,
    distinct from 2/3.
      • Xiang passes (0 marks), or marks only an endpoint 0 or 1: such marks are
        degenerate (a 0-length piece) and the multiset is still {2/3,1/3}; Liu
        claims 2/3.
      • Xiang marks b ∈ (0,2/3): pieces {b, 2/3−b, 1/3}, with b+(2/3−b)=2/3, so
        at most one of b, 2/3−b exceeds 1/3. Together with the piece 1/3, at
        least two of the three pieces are ≤ 1/3, so the median ≤ 1/3. With three
        pieces Liu claims ranks 1 and 3 = total − median ≥ 1 − 1/3 = 2/3.
      • Xiang marks b ∈ (2/3,1): pieces {2/3, b−2/3, 1−b}, with
        (b−2/3)+(1−b)=1/3, so both small pieces ≤ 1/3; median ≤ 1/3; Liu ≥ 2/3.
    Hence Liu ≥ 2/3 against every legal Xiang choice.
    Upper bound (no Liu choice forces more than 2/3). Let Liu's legal choice be
    arbitrary.
      • Liu passes (0 marks), or marks only endpoint(s) 0/1: the stick is one
        piece of length 1. Xiang marks 1/2 ∈ (0,1); pieces {1/2,1/2}; Liu claims
        one, total 1/2 ≤ 2/3.
      • Liu marks one interior point a ∈ (0,1). Reflect x ↦ 1−x if needed
        (preserves the piece multiset) to assume a ≥ 1/2, so [0,a] is the longer
        piece. Xiang marks b = 1/3; this is legal because 1/3 ∈ (0,1) and
        1/3 ≠ a (as a ≥ 1/2 > 1/3). The cuts {1/3, a} give pieces
        {1/3, a−1/3, 1−a}. For a ∈ [1/2,2/3]: a−1/3 ∈ [1/6,1/3] and
        1−a ∈ [1/3,1/2], so sorted (a−1/3) ≤ 1/3 ≤ (1−a) and the median is 1/3.
        For a ∈ [2/3,1): a−1/3 ∈ [1/3,2/3) and 1−a ∈ (0,1/3], so sorted
        (1−a) ≤ 1/3 ≤ (a−1/3) and the median is again 1/3. (Here a < 1 since a is
        interior; the endpoint a=1 is a degenerate mark already covered by the
        previous bullet.) Thus Liu's total = 1 − median = 1 − 1/3 = 2/3.
    So every Liu choice is held to ≤ 2/3, and the choice A_0={2/3} attains 2/3.
    By (B′), the supremum is attained at A_0, so c(1) = max_A inf_B O(A,B) = 2/3
    = 2^1/(2^2−1). ∎  This is the ONLY case with both directions and attainment.

(D) Matched strategy pair realising 2^n/(2^{n+1}−1) (exact; not an equilibrium).
    For any n ≥ 1: Liu geometric — segments 2^n, 2^{n−1},…,1 over D = 2^{n+1}−1.
    Xiang halving — cut each of the first n segments at its midpoint. Final pieces
    (units of 1/D): two copies of each of 2^{n−1},…,2 and three copies of 1.
    Sorted descending, the odd ranks pick one copy of each of 2^{n−1},…,2 (sum
    2^n−2) plus two of the three 1's (sum 2). Odd-rank sum = (2^n−2)+2 = 2^n.
    Hence the Liu-take of THIS pair is 2^n/D. ∎
    Consequence (rigorous, one-directional): inf_B O(geom_n, B) ≤ 2^n/D, because a
    specific Xiang response (halving) achieves O = 2^n/D. This proves nothing
    about whether some other Xiang response drives O lower (that is LB), or whether
    some other Liu configuration forces more (that is UB), and it does NOT assert
    that either strategy is a best response or that the pair is a Nash equilibrium
    (D5). Calling the pair "optimal" or an "equilibrium" would assume exactly the
    open statements (LB) and (UB).

Not established (open for n ≥ 2) — these are the two named defects D1 and D2:
  (LB) Key Lemma — for the geometric config, EVERY Xiang response gives
       O ≥ 2^n/D  (equivalently inf_B O(geom,B) = 2^n/D, not less). No continuum
       proof exists; finite grids / floating point cannot prove a universal
       "for every marking" claim. OPEN (D1, lower-bound side).
  (UB) Universal upper bound — for EVERY Liu configuration A (|A|≤n), Xiang has a
       response B with O(A,B) ≤ 2^n/D  (equivalently sup_A inf_B O(A,B) ≤ 2^n/D).
       No argument exists for n ≥ 2; only grid/numerical search over A (n ≤ 5),
       which does not certify a global supremum. OPEN (D1, upper-bound side; D2,
       the value is not shown to be attained — see (B′)).
The formula c(n) = 2^n/(2^{n+1}−1) for n ≥ 2 follows only if BOTH (LB) and (UB)
hold. Both are conjectured and supported by finite evidence only. Until they are
proved, the task's requested determination ("for each n, determine the largest c")
is discharged ONLY for n = 1.

# Open gaps
- D1 (primary): the requested determination is OPEN for n ≥ 2. It splits into the
  two universal statements (LB) and (UB) above, i.e. exactly the two minimax
  directions.
  • (LB) Key Lemma — OPEN for n ≥ 2 (proved for n = 1 via (C)). Statement: for
    the geometric config (segments 2^n,…,1 over D), every placement of ≤ n cuts
    gives odd-rank sum ≥ 2^n. Verified by exact grid search for n ≤ 3
    (min = 2^n/D exactly) and by floating-point search for n ≤ 5 (never below). A
    natural induction splits the largest segment 2^n (sum 2^n) from the tail
    geometric(n−1) (sum 2^n−1); the obstruction is a clean merge inequality —
    that the tail pieces landing at odd merged-positions outweigh the head pieces
    landing at even merged-positions. The merge inequality has resisted a clean
    inductive proof and is the main obstacle. Finite/FP tests cannot close it.
  • (UB) Universal upper bound — OPEN for n ≥ 2 (proved for n = 1 via (C)).
    Statement: for every Liu configuration A with |A| ≤ n, Xiang has a response B
    with O(A,B) ≤ 2^n/(2^{n+1}−1). No deductive argument exists for n ≥ 2;
    currently only grid/numerical search over A (n ≤ 5), which does not certify a
    global supremum.
- D2 (attainment / sup-vs-max): separated by (B′) into (i) sup-identification —
  PROVED for all n (the largest guaranteed value, as a supremum, is exactly
  sup_A inf_B O(A,B), with no attainment assumption); and (ii) attainment —
