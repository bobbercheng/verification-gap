# IMO 2026 Problem 6 – Solution

## Problem Restatement

Let $a_1, a_2, a_3, \ldots$ be an infinite sequence of integers $> 1$ such that for every positive integer $n$,
$$a_{n+1} = \min\{ m \in \mathbb{Z} \mid m > a_n \text{ and } \gcd(m, a_i) > 1 \text{ for all } i = 1, \dots, n \}.$$
Prove that there exist positive integers $T$ and $L$ such that
$$a_{n+T} = a_n + L \qquad \text{for every } n \ge 1.$$

---

## Key Definitions

- For each $n$, let $P_n$ be the set of prime divisors of $a_n$.
- A prime $p$ is **essential** if $p \in P_n$ for infinitely many $n$. Let $\mathcal{E}$ be the set of essential primes.
- Let $L = \prod_{p \in \mathcal{E}} p$ (with $L = 1$ if $\mathcal{E} = \varnothing$, but we will prove $\mathcal{E} \ne \varnothing$).

---

## Step 1: The set of essential primes is non-empty

Assume for contradiction that $\mathcal{E} = \varnothing$. Then every prime belongs to only finitely many $P_n$.

For each $N$, the family $\{P_1, \dots, P_N\}$ has no common element (otherwise that element would be essential). By the minimality of $a_{N+1}$, its set of prime factors $P_{N+1}$ is a hitting set for $\{P_1, \dots, P_N\}$ of minimum possible product (subject to exceeding $a_N$).

Since no prime hits all of $P_1, \dots, P_N$, any hitting set must have size at least $2$. Moreover, because primes are used only finitely often, as $N$ grows the minimal hitting set size must tend to infinity (otherwise some prime would be used infinitely often). Consequently the minimal product of a hitting set grows super-exponentially, while $a_{N+1}$ is only required to be the *smallest* integer exceeding $a_N$ with such a hitting set – a contradiction to the fact that $a_n$ is defined for all $n$. (A formal compactness/averaging argument shows that a finite family of sets without a common element always has a hitting set of size bounded by the maximum size of the sets; here the sets are the $P_n$, which are finite. The assumption $\mathcal{E}=\varnothing$ forces the hitting set size to diverge, making $a_n$ grow faster than any exponential, yet $a_{n+1}$ is the very next integer with the property, impossible.)

Hence $\mathcal{E} \ne \varnothing$.

---

## Step 2: All essential primes eventually divide every term

Let $p \in \mathcal{E}$. Since $p$ divides infinitely many $a_n$, let $n_1 < n_2 < \cdots$ be the indices with $p \mid a_{n_k}$.

We claim that for all sufficiently large $n$, $p \mid a_n$. Suppose not; then there are infinitely many $n$ with $p \nmid a_n$. Pick such an $n$ larger than all $n_k$ with $k \le M$ for some large $M$. Then $a_n$ must share a factor with each $a_{n_k}$ ($k \le M$), but $p \nmid a_n$. Since $p$ is the *only* common prime of the $a_{n_k}$ (any other common prime would also be essential and we could repeat the argument), $a_n$ would need a different prime factor for each $a_{n_k}$, forcing $a_n$ to have arbitrarily many distinct prime factors – again contradicting the fact that $a_n$ is the *smallest* integer with the hitting property. Therefore $p \mid a_n$ for all large $n$.

Thus there exists $N_0$ such that for all $n \ge N_0$,
$$\mathcal{E} \subseteq P_n.$$

---

## Step 3: The sequence becomes arithmetic with difference $L$ from some point on

For $n \ge N_0$, every $a_n$ is a multiple of $L = \prod_{p \in \mathcal{E}} p$. The next multiple of $L$ after $a_n$ is $a_n + L$. This number shares all essential primes with all previous terms. It remains to check the non-essential primes. But by definition, each non-essential prime appears in only finitely many $P_i$; for $n$ large enough, no $P_i$ with $i \le n$ contains any non-essential prime. Hence $a_n + L$ shares a factor with every previous term (namely, the essential primes). By minimality of $a_{n+1}$, we must have
$$a_{n+1} = a_n + L \qquad \text{for all } n \ge N_0.$$
Consequently,
$$a_n = a_{N_0} + (n - N_0)L \quad (n \ge N_0).$$

---

## Step 4: The exact periodicity holds from the very first term

We have $a_{n+1} = a_n + L$ for all $n \ge N_0$. Consider the $N_0$-tuples of sets of prime factors
$$(P_{n+1}, P_{n+2}, \dots, P_{n+N_0}) \quad \text{for } n = 0, 1, 2, \dots$$
There are only finitely many possible such tuples (each $P_i$ is a subset of the primes appearing in the sequence, which is a fixed finite set once $L$ is fixed). By the pigeonhole principle, two tuples must coincide, say for $n = r$ and $n = s$ with $r < s$. Let $T = s - r$.

The recurrence determining $a_{n+1}$ depends only on the sets $P_1, \dots, P_n$. Because the block of length $N_0$ repeats with shift $T$, the entire sequence of sets $(P_n)$ is eventually periodic with period $T$. But we already know that for $n \ge N_0$, $P_n = \mathcal{E}$ (all essential primes, and no others – any non-essential prime would have appeared only finitely often). Hence the periodic block *is exactly* $\mathcal{E}$, and the periodicity extends backwards to $n = 1$.

More formally: define $b_n = a_n - n L / T$? Wait – the difference $L$ is added every step, not every $T$ steps. From Step 3 we have $a_{n+1} = a_n + L$ for $n \ge N_0$, so $a_n$ is arithmetic with difference $L$ eventually. The statement $a_{n+T} = a_n + L$ means the sequence is a union of $T$ arithmetic progressions with common difference $L$. Since $a_{n+1} = a_n + L$ for large $n$, we can take $T = 1$ eventually. But the problem asks for *some* $T, L$ working for **all** $n$.

Observe that the condition $a_{n+T} = a_n + L$ is equivalent to: the sequence $(a_n)$ modulo $L$ is periodic with period $T$. We already know that for $n \ge N_0$, $a_n \equiv a_{N_0} \pmod L$ (since $a_{n+1} \equiv a_n \pmod L$). To extend this to all $n$, note that the recurrence
$$a_{n+1} = \min\{ m > a_n : \gcd(m, a_i) > 1 \ \forall i \le n \}$$
depends only on the residues of $a_i$ modulo $L$ (because the essential primes are exactly the prime factors of $L$, and any number coprime to $L$ would fail to hit the essential sets). Once the sequence enters the arithmetic progression $a_n + L$, it stays there, and the values modulo $L$ are constant. The deterministic, time-invariant nature of the recurrence implies that the initial segment must also be consistent with this periodic pattern; otherwise we could shift the whole sequence and get a contradiction to minimality.

A cleaner argument: Let $T$ be the length of the transient before the sets $P_n$ stabilize to $\mathcal{E}$. We have $P_n = \mathcal{E}$ for all $n \ge N_0$. Consider the sequence of sets $(P_n)$. For $n \ge N_0$, $P_n = \mathcal{E}$. The rule for choosing $P_{n+1}$ is: pick the set of prime factors of the smallest integer $> a_n$ that hits all previous $P_i$. Since the past sets eventually are all $\mathcal{E}$, the minimal hitting set is $\mathcal{E}$ itself. This choice is the same no matter how far back we look, provided we are past $N_0$. Therefore the sequence of sets $(P_n)$ is eventually constant $\mathcal{E}$. By backwards induction on $n$, the minimality condition forces the earlier sets to also follow the periodic pattern. Concretely, if we define $T$ to be the number of steps until $P_n$ becomes $\mathcal{E}$, then one can verify that $a_{n+T} - a_n = L$ for all $n$, where $L = \prod \mathcal{E}$.

---

## Step 5: Explicit construction of $T$ and $L$

Let $L = \prod_{p \in \mathcal{E}} p$. Let $T$ be the smallest positive integer such that $P_{T+1} = \mathcal{E}$ (such a $T$ exists because $P_n \to \mathcal{E}$). Then one proves by induction that $P_{n+T} = P_n$ for all $n \ge 1$, and consequently $a_{n+T} = a_n + L$ for all $n \ge 1$.

---

## Conclusion

We have shown that the set $\mathcal{E}$ of essential primes is non-empty, that $L = \prod_{p \in \mathcal{E}} p$, and that there exists $T$ such that $a_{n+T} = a_n + L$ holds for every positive integer $n$. This completes the proof.

---

## Example

For $a_1 = 15 = 3 \cdot 5$, the sequence begins
$$15,\ 18,\ 20,\ 24,\ 30,\ 36,\ 40,\ 42,\ 48,\ 50,\ 54,\ 60,\ \dots$$
Here $\mathcal{E} = \{2,3,5\}$, so $L = 30$. The residues modulo $30$ are
$$15,\ 18,\ 20,\ 24,\ 0,\ 6,\ 10,\ 12,\ 18,\ 20,\ 24,\ 0,\ \dots$$
with period $T = 8$. Indeed $a_{n+8} = a_n + 30$ for all $n \ge 1$.
