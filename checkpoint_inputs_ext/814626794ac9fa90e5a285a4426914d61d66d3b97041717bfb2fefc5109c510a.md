# IMO 2026 Problem 4 - Analysis

## Problem Restatement
Shan-Yu and Mulan play a game with a triangle T and a fixed angle θ (0° < θ < 180°). Shan-Yu chooses initial triangle T. Then they repeat:
1. If T has an angle exactly θ, Mulan wins.
2. Otherwise, Mulan chooses point P on perimeter of T (not a vertex), cuts from P to opposite vertex, splitting T into two triangles.
3. Shan-Yu discards one triangle; the other becomes new T.

**Question:** For which real values of θ can Mulan guarantee victory in finitely many steps, no matter how Shan-Yu plays?

## Key Observations
- State space: triangles up to similarity ≅ open 2-simplex Δ = {(A,B,C) | A,B,C > 0, A+B+C=180°}
- Mulan's move: pick vertex (angle A), choose split x ∈ (0,A). Two children:
  - T₁ = (x, B, 180°-B-x)  [preserves angle B]
  - T₂ = (A-x, C, B+x)      [preserves angle C]
- Shan-Yu chooses T₁ or T₂.
- Mulan wins iff some angle = θ.

## Immediate Win Condition
Mulan wins in one move iff she can choose x such that BOTH children have angle θ.
This requires: (x=θ or x=A+C-θ) AND (x=A-θ or x=θ-B).
Cases:
1. x=θ, x=A-θ → A=2θ, x=θ. Works for any θ < 90°.
2. x=θ, x=θ-B → B=0 impossible.
3. x=A+C-θ, x=A-θ → C=0 impossible.
4. x=A+C-θ, x=θ-B → A+B+C=2θ → 180°=2θ → θ=90°.

**Conclusion:** 
- For θ ≠ 90°: immediate win iff some angle = 2θ (cut it with x=θ).
- For θ = 90°: immediate win from ANY triangle (cut from A with x=90°-B).

## Hypothesis 1: θ > 90° → Shan-Yu wins
**Proof:** Shan-Yu starts with acute triangle (e.g., 60°-60°-60°). All angles < 90° < θ.
From an acute triangle, any Mulan move creating angle ≥ θ in one child makes the other child acute (all angles < 90° < θ). Shan-Yu picks the acute child. Game stays in acute triangles forever. Mulan never reaches θ. ✓

## Hypothesis 2: θ = 180°/2ⁿ (dyadic with numerator 1) → Mulan wins
**Strategy:** Iteratively force angles 2θ, 4θ, ..., 2ⁿ⁻¹θ = 90°.
- Base (θ=90°): Mulan wins in 1 move from any triangle.
- Step: Assume Mulan can force 2θ from any triangle without {2θ, 4θ, ..., 90°}. To force 2θ: cut from A with x = 2θ - B. Both children have angle 2θ. Shan-Yu must accept 2θ. Resulting triangle has angle 2θ but no smaller forbidden angles (by induction). Then Mulan uses the strategy for 2θ.
- After n-1 steps, triangle has 90°. Mulan cuts 90° with x=θ, both children have θ. Win in n moves total. ✓
