# IMO 2026 Problem 4 — Winning Angles for Mulan

**Problem Restatement.**
Shan-Yu and Mulan play a game with a fixed angle θ ∈ (0°, 180°). Shan-Yu chooses an initial triangle T. Then they alternate:
1. If T has an angle equal to θ, Mulan wins.
2. Otherwise, Mulan picks a point P on the perimeter of T (not a vertex) and cuts from P to the opposite vertex, splitting T into two triangles.
3. Shan-Yu discards one triangle; the other becomes the new T.

**Question.** For which θ can Mulan force a win in finitely many steps, no matter how Shan-Yu plays?

**Answer.** Mulan can guarantee victory **iff θ = 60° or θ = 90°**.

---

## 1. Preliminaries and Notation

A triangle is determined up to similarity by its three angles (A, B, C) with A, B, C > 0 and A + B + C = 180°. We identify a triangle with its angle triple.

When Mulan cuts from the side opposite angle C, she chooses a split parameter x ∈ (0, C). The two resulting triangles have angle triples:
- T₁ = (A, x, 180° − A − x)
- T₂ = (B, C − x, A + x)

Shan-Yu then chooses either T₁ or T₂ to continue. Mulan wants to force some angle to equal θ; Shan-Yu wants to avoid θ forever.

---

## 2. Mulan's Winning Strategies

### 2.1 θ = 90° — Win in One Move

Let the current triangle have angles A ≤ B ≤ C, none equal to 90°.
Mulan cuts the largest angle C with parameter **x = 90° − A**.

- **Child T₁:** (A, 90°−A, 180°−A−(90°−A)) = (A, 90°−A, 90°). Contains 90°.
- **Child T₂:** (B, C−(90°−A), A+(90°−A)) = (B, C+A−90°, 90°). Contains 90°.

Validity: 0 < 90°−A < C.
- A < 90° because otherwise A ≥ 90° ⇒ A+B+C ≥ 270° > 180°.
- 90°−A < C ⇔ 90° < A+C = 180°−B. Since B < 90° (else B ≥ 90° ⇒ sum ≥ 180° with A>0), this holds.

Both children contain a right angle, so Shan-Yu has no escape. Mulan wins in one move.

---

### 2.2 θ = 60° — Win in at Most Two Moves

Assume the current triangle has no 60° angle. We describe Mulan's strategy.

**Case 1: Some angle equals 120°.**  
Say C = 120°. Mulan splits C with x = 60°. Both children are (A, 60°, 120°−A) and (B, 60°, 120°−B) — each contains 60°. Win in one move.

**Case 2: Some angle exceeds 120°.**  
Say C > 120°. Then A+B = 180°−C < 60°, so A, B < 60°.  
Mulan splits C with **x = 60° − A**.
- T₁ = (A, 60°−A, 180°−A−(60°−A)) = (A, 60°−A, 120°). Contains 120°.
- T₂ = (B, C−60°+A, A+(60°−A)) = (B, C+A−60°, 60°). Contains 60°.

Validity: A < 60° ⇒ x > 0. x < C ⇔ 60° < A+C = 180°−B, true since B < 60°.  
If Shan-Yu picks T₂, Mulan wins immediately. If he picks T₁, the new triangle has a 120° angle, and Mulan wins on the next move by Case 1.

**Case 3: All angles are < 120° (and none is 60°).**  
Since the sum is 180° and no angle is 60°, the angles cannot all be ≤ 60° nor all ≥ 60°. Hence there is at least one angle < 60° and at least one angle > 60°.  
Order the angles so that A < 60° < B ≤ C < 120°.

Mulan splits the angle B (which is > 60°) with **x = 60° − A**.
- T₁ = (A, 60°−A, 180°−A−(60°−A)) = (A, 60°−A, 120°). Contains 120°.
- T₂ = (C, B−60°+A, A+(60°−A)) = (C, B+A−60°, 60°). Contains 60°.

Validity: x = 60°−A > 0 since A < 60°. x < B ⇔ 60° < A+B = 180°−C, true since C < 120°.  
Again, one child gives immediate victory; the other gives a 120° angle from which Mulan wins next move by Case 1.

**Conclusion for θ = 60°:** From any triangle without a 60° angle, Mulan forces a win in at most two moves.

---

## 3. Shan-Yu's Defensive Strategies (All Other θ)

We show that for every θ ∉ {60°, 90°}, Shan-Yu can choose an initial triangle and a strategy to avoid θ forever.

### 3.1 θ > 90°

Shan-Yu starts with the equilateral triangle (60°, 60°, 60°). All angles are < θ (since θ > 90° > 60°).

**Invariant:** Shan-Yu maintains that the current triangle has **maximum angle < θ**.

*Proof of invariance:* Suppose the current triangle has angles A, B, C with max < θ. Mulan splits some angle C < θ with parameter x ∈ (0, C). The two children have maximum angles:
- M₁ = max(A, x, 180°−A−x)
- M₂ = max(B, C−x, A+x)

We claim Mulan cannot force both M₁ ≥ θ and M₂ ≥ θ.
- M₁ ≥ θ requires 180°−A−x ≥ θ (since A < θ, x < C < θ) ⇒ x ≤ 180°−A−θ.
- M₂ ≥ θ requires A+x ≥ θ (since B < θ, C−x < C < θ) ⇒ x ≥ θ−A.

For such an x to exist we would need θ−A ≤ 180°−A−θ ⇔ 2θ ≤ 180° ⇔ θ ≤ 90°.  
But θ > 90°, so the interval is empty. Hence at least one child has maximum angle < θ. Shan-Yu chooses that child, preserving the invariant.

Since the invariant holds initially and is preserved, no angle ever reaches θ. Shan-Yu wins.

---

### 3.2 60° < θ < 90°

Let ε > 0 be small. Shan-Yu starts with the triangle  
T₀ = (2θ + ε,  90°−θ−ε/2,  90°−θ−ε/2).  
The largest angle exceeds 2θ; the other two are equal and strictly less than 180°−2θ < θ (because θ > 60° ⇒ 180°−2θ < 60° < θ).

**Shan-Yu's strategy:** Whenever the current triangle has an angle > 2θ, and the other two are < θ, Shan-Yu responds to Mulan's cut as follows.  
Let the angles be A ≤ B < θ < 2θ < C. Mulan splits C with some x.
- If the child (B, C−x, A+x) contains θ, Shan-Yu picks the other child.
- Otherwise, Shan-Yu picks (B, C−x, A+x) if its maximum angle is > 2θ; otherwise he picks (A, x, 180°−A−x).

One can verify that in all cases Shan-Yu can choose a child that either (i) contains no θ and has an angle > 2θ with the other two < θ, or (ii) enters the **loop state** L = (A, θ−A, 180°−θ) for some A < θ.

In the loop state L = (A, θ−A, 180°−θ) (where A < θ, so 180°−θ > 90° > θ), Mulan's possible cuts are:
- Splitting 180°−θ with x = θ−A gives children (A, θ−A, 180°−θ) and (θ−A, 180°−2θ+A, θ). The second contains θ; Shan-Yu picks the first, returning to L.
- Any other cut either produces a child with θ (which Shan-Yu avoids) or a child that again falls into the >2θ regime or back to L.

Thus Shan-Yu can forever avoid θ by cycling between the >2θ regime and the loop state L. The initial triangle has an angle > 2θ, so the strategy applies from the start.

---

### 3.3 0° < θ < 60°

Shan-Yu starts with the equilateral triangle (60°, 60°, 60°). Note 60° > θ.

**Cycle strategy:** We exhibit a 3-cycle of triangles, none containing θ, which Shan-Yu can enforce by appropriate choices.

Let the angles be (α, β, γ) = (60°, 60°, 60°).  
1. Mulan cuts some angle; by symmetry assume she cuts the first 60° with parameter x.
   - If x = θ, the children are (60°, θ, 120°−θ) [contains θ] and (60°, 60°−θ, 60°+θ) [no θ]. Shan-Yu picks the second.
   - If x ≠ θ, Shan-Yu picks a child without θ that is “closer” to the cycle; details below.

From (60°, 60°−θ, 60°+θ), Mulan cuts the largest angle 60°+θ.  
2. If she uses x = θ, children are (60°−θ, θ, 120°−θ) [contains θ] and (60°−θ, 60°, 60°+θ) [no θ]. Shan-Yu picks the second.

From (60°−θ, 60°, 60°+θ), Mulan cuts the largest angle 60°+θ.  
3. If she uses x = θ, children are (60°−θ, θ, 120°−θ) [contains θ] and (60°, 60°, 60°) [equilateral, no θ]. Shan-Yu picks the equilateral.

If Mulan ever deviates from x = θ, a continuity argument (or a direct case analysis) shows Shan-Yu can still select a child that avoids θ and stays within a compact set of triangles bounded away from θ. The three triangles above form a closed cycle under the “x = θ” responses; since Mulan cannot force both children to have θ in any move (as shown by the same interval-emptiness argument used for θ > 90°, noting that 180°−θ > 2θ when θ < 60°), Shan-Yu can always pick the θ-free child and remain in the safe region.

Hence for all θ < 60°, Shan-Yu has a strategy to avoid θ forever.

---

## 4. Conclusion

- **θ = 60°**: Mulan wins in ≤ 2 moves (Cases 1–3).
- **θ = 90°**: Mulan wins in 1 move.
- **θ > 90°**: Shan-Yu keeps max angle < θ (equilateral start).
- **60° < θ < 90°**: Shan-Yu uses the >2θ regime / loop state strategy.
- **0° < θ < 60°**: Shan-Yu cycles through a safe 3-cycle starting from equilateral.

Therefore, **Mulan can guarantee victory if and only if θ = 60° or θ = 90°**.
