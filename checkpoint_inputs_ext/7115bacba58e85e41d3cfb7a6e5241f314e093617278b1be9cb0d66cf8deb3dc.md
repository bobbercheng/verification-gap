## Problem
Let $\mathbb{R}_{>0}$ be the set of positive real numbers. Determine all functions $f :\mathbb{R}_{>0}\to \mathbb{R}_{>0}$ such that $\sqrt{\frac{x^2 + f(y)^2}{2}}\ge \frac{f(x) + y}{2} \ge \sqrt{xf(y)}$ for every $x,y\in\mathbb{R}_{>0}$.

## Approaches tried
- Checked affine guesses. The translations $f(x)=x+c$ satisfy the chain by RMS--AM--GM; multiplicative guesses $f(x)=kx$ appear to force $k=1$.
- Used the equality-producing substitution $x=f(y)$. This gives the exact second-iterate relation $f(f(y))=2f(y)-y$.
- Iterated the second-iterate relation. Every orbit is an arithmetic progression $f^n(x)=x+n(f(x)-x)$, so positivity forces $f(x)\ge x$.
- For two strictly positive displacements, synchronized their two arithmetic orbits up to bounded error and applied the upper inequality in both orders. This forces all positive displacements to be equal.
- If zero and positive displacements coexisted, the upper inequality would force every point of one type to be more than a fixed positive distance from every point of the other type. A finite-chain argument on $\mathbb R_{>0}$ rules this out.

## Current best
The expected complete characterization is $\boxed{f(x)=x+c\text{ for all }x>0}$, where $c$ is an arbitrary nonnegative real constant. The orbit-synchronization and no-mixing arguments have been found; a fully polished proof and independent sanity checks remain to be recorded.
