# IMO 2026 Problem 4 — Winning Angles for Mulan: Partial Result with Explicit Gaps

**Problem Restatement.**
Shan-Yu and Mulan play a game with a fixed angle θ ∈ (0°, 180°). Shan-Yu chooses an initial triangle T. Then they alternate:
1. If T has an angle equal to θ, Mulan wins.
2. Otherwise, Mulan picks a point P on the perimeter of T (not a vertex) and cuts from P to the opposite vertex, splitting T into two triangles.
3. Shan-Yu discards one triangle; the other becomes the new T.

**Question.** For which θ can Mulan force a win in finitely many steps, no matter how Shan-Yu plays?

## 1. Verified Winning Strategies

### 1.1 θ = 90° — Mulan Wins in 1 Move
Let the current triangle have angles A ≤ B ≤ C, none equal to 90°. Mulan splits the largest angle C with parameter **x = 90° − A**.

- **T₁** = (A, 90°−A, 180°−A−(90°−A)) = (A, 90°−A, **90°**). Contains 90°.
- **T₂** = (B, C−(90°−A), A+(90°−A)) = (B, A+C−90°, **90°**) = (B, 90°−B, **90°**). Contains 90°.

**Validity:** 0 < 90°−A < C holds because A < 90° (otherwise A+B+C ≥ 270° > 180°) and 90°−A < C ⇔ 90° < A+C = 180°−B, which holds since B < 90° (else sum ≥ 180°). Both children contain a right angle; Shan-Yu has no escape.

---

### 1.2 θ = 60° — Mulan Wins in ≤2 Moves
Assume no angle equals 60°.

**Case 1: Some angle = 120°.** Say C = 120°. Mulan splits C with x = 60°. Both children are (A, 60°, 120°−A) and (B, 60°, 120°−B) — each contains 60°. Win in 1 move.

**Case 2: Some angle > 120°.** Say C > 120°. Then A+B < 60°, so A, B < 60°. Mulan splits C with **x = 60° − A**.
- T₁ = (A, 60°−A, 180°−A−(60°−A)) = (A, 60°−A, **120°**). Contains 120°.
- T₂ = (B, C−60°+A, A+(60°−A)) = (B, C+A−60°, **60°**). Contains 60°.

Validity: x > 0 since A < 60°. x < C ⇔ 60° < A+C = 180°−B ⇔ B < 60°, true. If Shan-Yu picks T₂, Mulan wins immediately. If T₁, the new triangle has a 120° angle → Case 1 applies next move.

**Case 3: All angles < 120° (and none = 60°).** Since sum = 180° and no angle is 60°, the angles cannot all be ≤ 60° nor all ≥ 60°. Hence ∃ angle < 60° and ∃ angle > 60°. Order so A < 60° < B ≤ C < 120°. Mulan splits B with **x = 60° − A**.
- T₁ = (A, 60°−A, 120°). Contains 120°.
- T₂ = (C, B−60°+A, 60°). Contains 60°.

Validity: x > 0. x < B ⇔ 60° < A+B = 180°−C ⇔ C < 120°, true. Again, one child gives immediate victory; the other gives 120° (Case 1).

---

### 1.3 θ > 90° — Shan-Yu Wins (Max-Angle Invariant)
Let θ = 90° + ε, ε > 0. Shan-Yu starts with the equilateral triangle (60°, 60°, 60°). All angles < θ.

**Invariant:** The current triangle has maximum angle < θ.

*Proof of invariance:* Suppose current triangle has angles A, B, C with max < θ. Mulan splits some angle C < θ with x ∈ (0, C). The children have maximum angles:
- M₁ = max(A, x, 180°−A−x)
- M₂ = max(B, C−x, A+x)

Mulan can force both M₁ ≥ θ and M₂ ≥ θ only if ∃ x satisfying:
- M₁ ≥ θ ⇒ 180°−A−x ≥ θ (since A < θ, x < C < θ) ⇒ x ≤ 180°−A−θ
- M₂ ≥ θ ⇒ A+x ≥ θ (since B < θ, C−x < C < θ) ⇒ x ≥ θ−A

Such x exists iff θ−A ≤ 180°−A−θ ⇔ 2θ ≤ 180° ⇔ θ ≤ 90°. But θ > 90°, so the interval is empty. At least one child has max < θ. Shan-Yu chooses that child, preserving the invariant.

Since the invariant holds initially and is preserved, no angle ever reaches θ. Shan-Yu wins.

## 2. Gap Analysis: Open Intervals (0°, 60°) and (60°, 90°)

### 2.1 Failed Mulan Strategies (Claimed Wins)

#### Strategy A: "Phase 1: Force 90°, Phase 2: Euclidean Algorithm on Angles Modulo θ" (0° < θ < 60°)
*From runs 900aa8a6d5ad, a4bd787d33ef*

**Claim:** Mulan forces a right triangle, then repeatedly splits the 90° angle with x = θ, using a Euclidean algorithm on the acute angles modulo θ to eventually hit a multiple of θ.

**Fatal Gaps (per `review_v1.json`):**
1. **Euclidean algorithm on real numbers does not terminate.** The strategy assumes repeated subtraction of θ from an angle eventually yields an exact multiple of θ. For irrational θ/90° ratios, this process takes infinitely many steps — no finite win.
2. **False invariant: "Sum of angles not multiples of θ strictly decreases."** Total angle sum is constant (180°). The sum of non-multiples cannot strictly decrease without bound; the measure is ill-defined on reals without a discrete well-founded order.
3. **No discrete well-founded measure provided.** The proof requires a measure like lexicographic order on (⌊angle/θ⌋, {angle/θ}) or a projective invariant, but none was constructed or proven to decrease.

#### Strategy B: "Force ≥θ, Then Euclidean Algorithm to 2θ" (60° < θ < 90°)
*From runs 900aa8a6d5ad, a4bd787d33ef*

**Claim:** Mulan first forces an angle ≥ θ (Step 1), then iteratively reduces the large angle by θ until hitting exactly 2θ, then wins (Steps 2–3).

**Fatal Gaps (per `review_v1.json`):**
1. **Step 1 angle formula error.** The claimed interval for the forcing parameter β is incorrect. The correct children when splitting C with β are T₁ = (A, β, 180°−A−β) and T₂ = (B, C−β, A+β). The condition for both children to have an angle ≥ θ is β ∈ [θ−A, min(C, B+C−θ)], not the interval stated in the candidates.
2. **Shan-Yu's choice between two ≥θ angles unhandled.** When T₂ = (B, C−θ, A+θ) has *both* C−θ ≥ θ and A+θ ≥ θ (i.e., C ≥ 2θ and A > 0), Shan-Yu can choose which large angle to keep. The strategy assumes Mulan controls this choice; she does not.
3. **Euclidean algorithm termination on reals.** Same as Strategy A — no finite termination guarantee for irrational angles.

### 2.2 Failed Shan-Yu Strategies (Claimed Defenses)

#### Defense A: "3-Cycle from Equilateral" (0° < θ < 60°)
*From run a8a6420ee2a0*

**Claim:** Shan-Yu starts with (60°, 60°, 60°) and maintains a 3-cycle:
(60, 60, 60) → (60, 60−θ, 60+θ) → (60−θ, 60, 60+θ) → (60, 60, 60)
by always picking the child without θ when Mulan plays x = θ.

**Fatal Gap (per `review_v1.json` for a8a6420ee2a0):**
- **Fails at θ = 30°:** Mulan splits 60° with x = 30°. Children are (60, 30, 90) and (60, 30, 90) — **BOTH contain 30°**. Shan-Yu cannot avoid θ on the first move.
- **Fails at θ = 20°:** Same issue — both children contain 20° when Mulan plays x = 20°.
- The "interval-emptiness argument from θ > 90°" was incorrectly invoked. That argument concerned forcing max angle ≥ θ, which is a *different* condition from forcing an angle *exactly equal* to θ. The two problems are not analogous.

#### Defense B: ">2θ Regime + Loop State L" (60° < θ < 90°)
*From run a8a6420ee2a0*

**Claim:** Shan-Yu starts with an angle > 2θ and maintains either:
- **Regime 1:** A triangle with an angle > 2θ and the other two < θ, or
- **Regime 2 (Loop State L):** L = (A, θ−A, 180°−θ) for some A < θ.

**Fatal Gap (per `review_v1.json`):**
- **No complete case analysis for arbitrary Mulan moves.** The candidate only checks Mulan's move x = θ−A in state L. For a general loop state L = (A, θ−A, 180°−θ), Mulan can split the 180°−θ angle with *any* x ∈ (0, 180°−θ). The children are T₁ = (A, x, 180°−A−x) and T₂ = (θ−A, 180°−θ−x, A+x). It is **not shown** that for every x ≠ θ−A, at least one child both avoids θ and satisfies one of the two invariant conditions. This is a substantial gap covering infinitely many possible Mulan moves.

## 3. Correct State Transition (Verified)

When Mulan splits angle C with parameter x ∈ (0, C), keeping angles A and B:
- **T₁** = (A, x, 180°−A−x) — preserves angle A
- **T₂** = (B, C−x, A+x) — preserves angle B

*Verified in `operator_audit.md` (run 8733bc088d4d) and used in all verified strategies above.*

**Common error (do not repeat):** Early runs used T₁ = (A, x, 180°−A−x) and T₂ = (180°−B−x, B, x) — incorrectly giving both children the same free angle x.
