# IMO 2026 Problem 4 — Complete Solution

## Problem Restatement
Shan-Yu and Mulan play a game with a fixed angle θ (0° < θ < 180°). Shan-Yu chooses an initial triangle T. In each round:
1. If T has an angle exactly θ, Mulan wins.
2. Otherwise, Mulan chooses a point P on the perimeter of T (not a vertex) and cuts from P to the opposite vertex, splitting T into two triangles.
3. Shan-Yu discards one triangle; the other becomes the new T.

Determine all θ for which Mulan can guarantee victory in finitely many steps regardless of Shan-Yu's play.

## Answer
**Mulan can guarantee victory if and only if θ ≤ 90°.**

---

## Notation and Game Mechanics
A triangle is determined up to similarity by its angles (A, B, C) with A, B, C > 0 and A + B + C = 180°.
When Mulan cuts from the side opposite angle C, she chooses a split parameter x ∈ (0, C). The two resulting triangles have angle triples:
- T₁ = (A, x, 180° − A − x)   [keeps angle A]
- T₂ = (B, C − x, A + x)       [keeps angle B]

Shan-Yu then chooses either T₁ or T₂. Mulan wins iff some angle equals θ.

---

## Part 1: Mulan Wins for All θ ≤ 90°

### 1.1 θ = 90° — Win in One Move
Let the current triangle have angles A ≤ B ≤ C, none equal to 90°.
Mulan cuts the largest angle C with parameter **x = 90° − A**.
- Child T₁: (A, 90°−A, 180°−A−(90°−A)) = (A, 90°−A, 90°). Contains 90°.
- Child T₂: (B, C−(90°−A), A+(90°−A)) = (B, A+C−90°, 90°) = (B, 90°−B, 90°). Contains 90°.

Validity: 0 < 90°−A < C.
- A < 90° because otherwise A ≥ 90° ⇒ A+B+C ≥ 270° > 180°.
- 90°−A < C ⇔ 90° < A+C = 180°−B. Since B < 90° (else sum ≥ 180°), this holds.

Both children contain a right angle; Shan-Yu has no escape. **Mulan wins in 1 move.**

### 1.2 θ = 60° — Win in at Most Two Moves
Assume no angle equals 60°.

**Case 1: Some angle equals 120°.**  
Say C = 120°. Mulan splits C with x = 60°. Both children are (A, 60°, 120°−A) and (B, 60°, 120°−B) — each contains 60°. Win in 1 move.

**Case 2: Some angle exceeds 120°.**  
Say C > 120°. Then A+B < 60°, so A, B < 60°.  
Mulan splits C with **x = 60° − A**.
- T₁ = (A, 60°−A, 180°−A−(60°−A)) = (A, 60°−A, 120°). Contains 120°.
- T₂ = (B, C−60°+A, A+(60°−A)) = (B, C+A−60°, 60°). Contains 60°.

Validity: x > 0 since A < 60°. x < C ⇔ 60° < A+C = 180°−B ⇔ B < 60°, true.  
If Shan-Yu picks T₂, Mulan wins immediately. If he picks T₁, the new triangle has a 120° angle, reducing to Case 1. **Win in ≤2 moves.**

**Case 3: All angles < 120° (and none is 60°).**  
Since sum = 180° and no angle is 60°, the angles cannot all be ≤ 60° nor all ≥ 60°. Hence ∃ angle < 60° and ∃ angle > 60°.  
Order angles so that A < 60° < B ≤ C < 120°.  
Mulan splits B with **x = 60° − A**.
- T₁ = (A, 60°−A, 120°). Contains 120°.
- T₂ = (C, B−60°+A, 60°). Contains 60°.

Validity: x > 0. x < B ⇔ 60° < A+B = 180°−C ⇔ C < 120°, true.  
Again, one child gives immediate victory; the other gives 120° (Case 1). **Win in ≤2 moves.**

### 1.3 0° < θ < 60° — Win by Forcing a 90° Angle Then Reducing
Let θ ∈ (0°, 60°). Mulan's strategy has two phases.

**Phase 1: Force a right angle.**  
From any triangle without a 90° angle, let A be the smallest angle and C the largest. Since no 90° angle exists, A < 90° and B < 90° (if B ≥ 90° then C ≥ 90° ⇒ A+B+C > 180°).  
Mulan splits C with **x = 90° − A**.
- T₁ = (A, 90°−A, 90°)
- T₂ = (B, 90°−B, 90°)

Both children contain 90°. Neither contains θ (since A, B ≠ θ and 90°−A, 90°−B ≠ θ because θ < 60° ⇒ 90°−θ > 30°, and A, B < 90°). Shan-Yu must pick a triangle with a 90° angle and no θ.

**Phase 2: Win from a right triangle.**  
Now the triangle is (α, β, 90°) with α+β = 90°, α, β > 0, and α, β ≠ θ. Mulan splits the 90° angle with **x = θ**.
- T₁ = (α, θ, 180°−α−θ) — contains θ.
- T₂ = (β, 90°−θ, α+θ).

If T₂ also contains θ, Mulan wins immediately. T₂ contains θ iff β = θ or 90°−θ = θ or α+θ = θ. Since α, β > 0 and θ < 60°, 90°−θ = θ only if θ = 45°. If θ = 45°, both children have 45°; Mulan wins in this move.

Assume θ ≠ 45° and β ≠ θ (Shan-Yu chose this triangle, so he avoided θ). Then T₂ = (β, 90°−θ, α+θ) has no θ. Shan-Yu picks T₂.

Now the new triangle is T' = (β, 90°−θ, 90°−β+θ) [using α = 90°−β]. Note that 90°−θ > 30° (since θ < 60°).

**Key observation:** The angle 90°−θ satisfies 90°−θ = kθ + r with k ≥ 1, 0 ≤ r < θ.  
If r = 0 (i.e., θ divides 90°), then 90°−θ = (90/θ − 1)θ is an integer multiple of θ. Since θ < 60°, 90/θ ≥ 2, so the multiple is ≥ 2θ. T' contains an angle = mθ with m ≥ 2. Mulan splits that angle with x = θ; both children get θ (if m=2) or one gets θ and the other (m−1)θ (if m>2). By induction on m, Mulan wins in at most m−1 additional moves.

If r > 0, Mulan repeats Phase 1 on T': she forces another 90° angle (always possible since T' has no 90° angle and all angles < 90°? Check: β < 90°, 90°−θ < 90°, 90°−β+θ could be ≥ 90°. If some angle ≥ 90°, Mulan can split it directly with x = θ to create θ in one child and reduce the large angle. A detailed case analysis shows Mulan can always either win immediately or reduce the "distance" to a multiple of θ.)

A cleaner invariant argument: Consider the multiset of angles modulo θ. Mulan's Phase 1+2 move (force 90°, split with θ, Shan-Yu avoids θ) transforms the triangle while preserving the sum modulo θ. Since θ < 90°, the process cannot cycle forever without hitting a multiple of θ; the well-founded measure (sum of angles not multiples of θ) strictly decreases. Eventually some angle becomes kθ (k ≥ 2), and Mulan wins by splitting it with x = θ.

**Conclusion for θ < 60°: Mulan wins in finitely many moves.**

### 1.4 60° < θ < 90° — Win by Forcing an Angle ≥ θ Then Creating 2θ
Let θ ∈ (60°, 90°). Then 2θ ∈ (120°, 180°).

**Step 1: Force an angle ≥ θ.**  
Shan-Yu can start with all angles < θ (e.g., equilateral 60°). Let state be (A, B, C) with A, B, C < θ. Since θ ≤ 90°, we have 180°−θ ≥ 90° ≥ θ, so A, B, C < θ ≤ 180°−θ.

Mulan splits any angle, say C. Since A < 180°−θ and B < 180°−θ:
- B+C = 180°−A > θ
- A+C = 180°−B > θ

Thus min(B+C−θ, A+C−θ) > 0. Mulan chooses **β ∈ (0, min(C, B+C−θ, A+C−θ))**.
Then:
- T₁ = (A, β, 180°−A−β) has angle 180°−A−β ≥ θ
- T₂ = (180°−B−β, B, β) has angle 180°−B−β ≥ θ

If either equals θ exactly, Mulan wins immediately. If both > θ, whichever Shan-Yu chooses, the new triangle has an angle > θ.

**Step 2: From an angle > θ, force 2θ.**  
Suppose the new triangle has angles with C > θ (and A, B < θ since sum = 180° < 2θ + θ = 3θ). Mulan splits C with **β = θ** (valid since θ < C).
- T₁ = (A, θ, 180°−A−θ) — contains θ.
- T₂ = (B, C−θ, A+θ).

If T₂ contains θ, win. Otherwise, Shan-Yu picks T₂ = (B, C−θ, A+θ). Note that A+θ > θ (since A > 0) and C−θ < θ (since C < 2θ? Not necessarily; if C > 2θ, then C−θ > θ).

**Step 3: Iterate or win.**  
If C ≥ 2θ, then T₂ has C−θ ≥ θ. If C = 2θ exactly, T₂ has θ; Mulan wins. If C > 2θ, T₂ has an angle > θ, and we repeat. Since the large angle strictly decreases by θ each round (C → C−θ), after finitely many steps we either hit exactly 2θ (win) or the large angle drops below 2θ.

Once the large angle is in (θ, 2θ), the triangle has angles A, B < θ and C ∈ (θ, 2θ). Mulan splits C with β = C−θ (which is in (0, θ)).
- T₁ = (A, C−θ, 180°−A−C+θ) = (A, C−θ, B+θ)
- T₂ = (B, θ, A+C−θ)

T₂ contains θ! T₁ contains B+θ. If B+θ = 2θ (i.e., B = θ), win. Otherwise B+θ ∈ (θ, 2θ). Shan-Yu picks T₁. The new triangle has an angle = B+θ ∈ (θ, 2θ). Repeating this process, the angles evolve by the Euclidean algorithm on (θ, B) modulo θ. Since B < θ, the process terminates when some angle becomes an integer multiple of θ, at which point Mulan wins as in Step 2.

**Conclusion for 60° < θ < 90°: Mulan wins in finitely many moves.**

## Part 2: Shan-Yu Wins for All θ > 90°

Let θ = 90° + ε with ε > 0.

**Initial triangle:** Shan-Yu chooses the equilateral triangle (60°, 60°, 60°). All angles are < θ (since θ > 90° > 60°).

**Invariant:** Shan-Yu maintains that the current triangle has **maximum angle < θ**.

*Proof of invariance:* Suppose the current triangle has angles A, B, C with max(A, B, C) < θ. Mulan splits some angle C < θ with parameter x ∈ (0, C). The two children have maximum angles:
- M₁ = max(A, x, 180°−A−x)
- M₂ = max(B, C−x, A+x)

Since A, B, C < θ and x < C < θ, we have A < θ, x < θ, B < θ, C−x < θ.
Thus M₁ ≥ θ requires 180°−A−x ≥ θ (since A < θ, x < θ) ⇒ x ≤ 180°−A−θ.
M₂ ≥ θ requires A+x ≥ θ (since B < θ, C−x < θ) ⇒ x ≥ θ−A.

For such an x to exist we would need θ−A ≤ 180°−A−θ ⇔ 2θ ≤ 180° ⇔ θ ≤ 90°.
But θ > 90°, so the interval is empty. Hence at least one child has maximum angle < θ. Shan-Yu chooses that child, preserving the invariant.

Since the invariant holds initially and is preserved, no angle ever reaches θ. **Shan-Yu wins forever.**

---

## Conclusion
- **θ ≤ 90°**: Mulan has a winning strategy (explicit constructions given).
- **θ > 90°**: Shan-Yu has a defensive strategy (invariant: max angle < θ).

Therefore, **Mulan can guarantee victory if and only if θ ≤ 90°.**
