# IMO 2026 Problem 4 — Winning Angles for Mulan

**Problem.** Fixed θ ∈ (0°,180°). Shan-Yu picks the initial triangle T. Repeat: if T has
an angle equal to θ, Mulan wins; else Mulan cuts from a perimeter point P (not a vertex)
to the opposite vertex, splitting T into two triangles; Shan-Yu discards one, the other is
the new T. For which θ can Mulan force a win in finitely many steps regardless of Shan-Yu?

**STATUS (this run): PARTIAL — under active investigation.**

## Verified core mechanics (transition)

Splitting angle C with parameter x ∈ (0,C) (keeping angles A and B in the two children):
- T₁ = (A, x, 180°−A−x)
- T₂ = (B, C−x, A+x)
Mulan may choose to split any of the three angles.

## Reproduced verified assets (re-checked in this run)

- **θ = 90°: Mulan wins in 1 move.** Order A≤B≤C with no 90°. Split C with x=90°−A.
  T₁=(A,90−A,90), T₂=(B,C−(90−A),A+(90−A))=(B,A+C−90,90)=(B,90−B,90). Both contain 90°.
  Valid: A<90°; 90−A<C ⟺ 90<A+C=180−B ⟺ B<90°. ✓
- **θ = 60°: Mulan wins in ≤2 moves.** If an angle =120°, split with x=60°, both children
  get 60°. If an angle >120° (say C), then A+B<60°, split C with x=60−A: T₂=(B,C−60+A,60)
  has 60°; T₁=(A,60−A,120) has 120°→Case1 next move. If all angles <120° and none=60°, then
  ∃ A<60<B≤C<120°; split B with x=60−A: T₁=(A,60−A,120), T₂=(C,B−60+A,60). ✓
  (Re-verified all validity conditions: x>0, x<angle.)
- **θ > 90°: Shan-Yu wins.** Start equilateral (60,60,60). Invariant: max angle < θ. Splitting
  C<θ with x: to force BOTH children max ≥θ needs 180−A−x≥θ AND A+x≥θ ⟹ θ−A ≤ x ≤ 180−A−θ,
  nonempty iff 2θ≤180° iff θ≤90°. Empty for θ>90°, so a safe child always exists. ✓
- **One-move win when an angle equals 2θ:** splitting angle 2θ with x=θ gives
  T₁=(A,θ,180−A−θ), T₂=(B,θ,A+θ); both contain θ. ✓
