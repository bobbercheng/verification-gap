# imo-2026-05 — tracking file

## Status
solved

## Problem
Let $\mathbb{R}_{>0}$ be the set of positive real numbers. Determine all functions $f :\mathbb{R}_{>0}\to \mathbb{R}_{>0}$ such that

\[
\sqrt{\frac{x^2 + f(y)^2}{2}}\ge \frac{f(x) + y}{2} \ge \sqrt{xf(y)}
\]

for every $x,y\in\mathbb{R}_{>0}$.

## Approaches tried
1. Numerical brute-force search — only $f(x)=x+c$ with $c\ge 0$ passed.
2. Functional equation $f(f(x)) = 2f(x) - x$ derived by setting $x=f(y)$.
3. Reformulation with $g(x)=f(x)-x$, identities $A+B=2(x-f(y))^2$, $A-B=-2(g(x)-g(y))(g(x)+g(y)+2x+2y)$.
4. Density argument using arithmetic progressions to force $g$ constant.
5. Covering argument eliminating the possibility of $g$ taking both $0$ and $c>0$.

## Current best
**Answer:** $f(x) = x + c$ for some constant $c \ge 0$.

## Full proof

Let $f:\mathbb{R}_{>0}\to\mathbb{R}_{>0}$ satisfy for all $x,y>0$

\[
\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)} . \tag{1}
\]

All quantities are positive, so squaring preserves the inequalities:

\[
2x^2 + 2f(y)^2 \ge (f(x)+y)^2 \ge 4x f(y) \qquad \forall x,y>0. \tag{2}
\]

---

### 1.  A functional equation

Take $x = f(y)$ (which is positive) in (2).  Then the left‑hand side becomes $2f(y)^2+2f(y)^2 = 4f(y)^2$ and the right‑hand side becomes $4f(y)\,f(y) = 4f(y)^2$.  Hence the whole chain collapses to equality:

\[
\bigl(f(f(y)) + y\bigr)^2 = 4f(y)^2 .
\]

Because all quantities are positive we may take square roots and obtain

\[
f(f(y)) + y = 2f(y) \qquad\Longrightarrow\qquad 
\boxed{f(f(x)) = 2f(x) - x \qquad \forall x>0.} \tag{3}
\]

Set  

\[
g(x) = f(x) - x \qquad (x>0).
\]

Then $g(x) > -x$ (since $f(x)>0$) and (3) rewrites as  

\[
x+g(x) + g(x+g(x)) = 2x + 2g(x) - x \;\Longrightarrow\;
\boxed{g(x+g(x)) = g(x) \qquad \forall x>0.} \tag{4}
\]

---

### 2.  Algebraic reformulation

Write $a = g(x)$, $b = g(y)$, so $f(x)=x+a$, $f(y)=y+b$.  The two inequalities in (2) become  

\[
\begin{aligned}
A(x,y) &:= 2x^2 + 2(y+b)^2 - (x+y+a)^2 \ge 0, \\
B(x,y) &:= (x+y+a)^2 - 4x(y+b) \ge 0 .
\end{aligned}
\]

A direct expansion gives  

\[
\begin{aligned}
A(x,y) &= (x-y)^2 - a^2 - 2a(x+y) + 4by + 2b^2 ,\\
B(x,y) &= (x-y)^2 + a^2 + 2a(x+y) - 4bx .
\end{aligned}
\]

From these we obtain two fundamental identities  

\[
\begin{aligned}
A(x,y) + B(x,y) &= 2\bigl(x - y - b\bigr)^2 = 2\bigl(x - f(y)\bigr)^2 , \tag{5}\\
A(x,y) - B(x,y) &= -2(a-b)(a+b+2x+2y). \tag{6}
\end{aligned}
\]

Because $A,B\ge 0$, we have $|A-B| \le A+B$ (the absolute difference of two non‑negative numbers cannot exceed their sum).  Substituting (5) and (6) and cancelling a factor $2$ yields  

\[
\boxed{|g(x)-g(y)|\,\bigl(g(x)+g(y)+2x+2y\bigr) \le \bigl(x - y - g(y)\bigr)^2 \qquad \forall x,y>0.} \tag{7}
\]

Swapping $x$ and $y$ gives the symmetric inequality  

\[
|g(x)-g(y)|\,\bigl(g(x)+g(y)+2x+2y\bigr) \le \bigl(y - x - g(x)\bigr)^2 \qquad \forall x,y>0. \tag{8}
\]

---

### 3.  First consequence – at most one positive value

Let $V = \{g(x) : x>0\}$.  Suppose $V$ contains two distinct positive numbers $c_1 > c_2 > 0$.  Choose $u,v>0$ with $g(u)=c_1$, $g(v)=c_2$.  From the functional equation (4) we obtain  

\[
g(u + n c_1) = c_1,\qquad g(v + m c_2) = c_2 \qquad \forall n,m\in\mathbb{N}_0 .
\]

Insert $x = u + n c_1$, $y = v + m c_2$ into (7).  With $a=c_1$, $b=c_2$,

\[
(c_1-c_2)\bigl(c_1+c_2 + 2u + 2v + 2n c_1 + 2m c_2\bigr) \le \bigl(u - v - c_2 + n c_1 - m c_2\bigr)^2 . \tag{9}
\]

If $c_1/c_2 \in \mathbb{Q}$, write $c_1 = \frac{p}{q}c_2$ with $p,q\in\mathbb{N}$ coprime.  Choose $n = p t$, $m = q t$ for $t\in\mathbb{N}$.  Then $n c_1 - m c_2 = 0$, so the right‑hand side of (9) equals the constant $(u-v-c_2)^2$, while the left‑hand side grows linearly with $t$.  For large $t$ the inequality fails – contradiction.

If $c_1/c_2 \notin \mathbb{Q}$, the set $\{n c_1 - m c_2 : n,m\in\mathbb{N}_0\}$ is dense in $\mathbb{R}$ (a classical consequence of the irrational ratio).  Hence we can find sequences $(n_k,m_k)\to(\infty,\infty)$ such that $n_k c_1 - m_k c_2 \to -(u - v - c_2)$.  Then the right‑hand side of (9) tends to $0$ while the left‑hand side tends to $+\infty$, again a contradiction.

Thus $V$ contains **at most one** positive number.  Together with $0$, we have  

\[
V \subseteq \{0, c\} \quad\text{for some } c\ge 0 .
\]

If $c=0$ then $g\equiv 0$, i.e. $f(x)=x$, which is a solution.  From now on suppose $c>0$ and that **both** $0$ and $c$ occur; we shall derive a contradiction.

---

### 4.  Inequalities between the two level sets

Let  

\[
S_0 = \{x>0 : g(x)=0\},\qquad S_c = \{x>0 : g(x)=c\},
\]

both non‑empty.  For $x\in S_0,\;y\in S_c$ we have $a=0,\;b=c$.  Substituting into the formulas for $A$ and $B$ and using $A,B\ge 0$ gives  

\[
\begin{aligned}
A(x,y) = (x-y)^2 + 4cx + 2c^2 \ge 0 &\quad\text{(always true)},\\
B(x,y) = (x-y)^2 - 4cx \ge 0 &\Longrightarrow (x-y)^2 \ge 4cx , \tag{10}\\
A(y,x) = (x-y)^2 - c^2 - 2c(x+y) \ge 0 &\Longrightarrow (x-y)^2 \ge c^2 + 2c(x+y) . \tag{11}
\end{aligned}
\]

Inequality (11) implies $(x-y)^2 \ge c^2$, hence  

\[
|x-y| \ge c \qquad \forall\,x\in S_0,\;y\in S_c . \tag{12}
\]

Moreover, equality $|x-y|=c$ cannot occur because it would mean $x = y \pm c$.  If $y\in S_c$, then by (4) $y+c\in S_c$, and also $y-c\in S_c$ whenever $y>c$ (using $f^{-1}(y)=2y-f(y)=y-c$ and the same computation as below).  Thus $x$ would belong to $S_c$, contradicting $x\in S_0$.  Hence the inequality is strict:

\[
|x-y| > c \qquad \forall\,x\in S_0,\;y\in S_c . \tag{13}
\]

---

### 5.  Structure of $S_c$

Take any $y\in S_c$.  From (4) we have $y+c \in S_c$.  Also, if $y > c$, then $y-c \in S_c$.  Indeed, from $f(f^{-1}(y)) = y$ and $f^{-1}(y) = 2y - f(y) = y-c$ (which follows from (3) by replacing $x$ with $f^{-1}(y)$), we get  

\[
g(y-c) = f(y-c) - (y-c) = y - (y-c) = c .
\]

Thus the whole two‑sided arithmetic progression $\{y_0 + n c : n\in\mathbb{Z},\; y_0 + n c >0\}$ is contained in $S_c$, where $y_0$ is the smallest positive member of this orbit.  Because we can move backward as long as we stay positive, the minimal positive element $y_0$ satisfies $0 < y_0 \le c$ (otherwise $y_0-c>0$ would be a smaller element of the orbit).

Consequently, the set  

\[
P = \{y_0 + n c : n\in\mathbb{N}_0\}
\]

is contained in $S_c$ and its points are spaced by exactly $c$.

---

### 6.  Covering argument – contradiction

Consider the closed intervals  

\[
I_n = [\,y_0 + n c - c,\; y_0 + n c + c\,] \qquad (n\ge 0).
\]

Their union covers all positive real numbers.  Indeed,
- $I_0 = [y_0-c,\; y_0+c]$; because $0<y_0\le c$, the left endpoint $y_0-c \le 0$, so $I_0$ contains $(0,\; y_0+c]$.
- $I_1 = [y_0,\; y_0+2c]$, $I_2 = [y_0+c,\; y_0+3c]$, … .  
Since $I_n$ and $I_{n+1}$ overlap (their intersection is $[y_0+nc,\; y_0+(n+1)c]$), the union $\bigcup_{n\ge 0} I_n$ is precisely $(0,\infty)$.

For any $x>0$ there exists some $n\ge 0$ such that $x\in I_n$, i.e.  

\[
|x - (y_0 + n c)| \le c .
\]

If $x\in S_0$, then by (13) we must have $|x - (y_0 + n c)| > c$ for all $n$, because each $y_0 + n c$ lies in $S_c$.  This contradicts the covering property just established.  Therefore $S_0$ must be empty.

---

### 7.  Conclusion

Since $S_0 = \emptyset$, the function $g$ never takes the value $0$; together with §3 we obtain $g(x) \equiv c$ for the constant $c>0$.  Hence  

\[
f(x) = x + c \qquad (c > 0).
\]

Combined with the previously found solution $f(x)=x$ (which corresponds to $c=0$), all solutions are  

\[
\boxed{f(x) = x + c \quad\text{for some constant } c \ge 0.}
\]

A direct check shows that for any $c\ge 0$ the function satisfies the original inequalities: they become the Quadratic‑Mean–Arithmetic‑Mean and the Arithmetic‑Mean–Geometric‑Mean inequalities for the two positive numbers $x$ and $y+c$, which are universally true.

Thus the set of solutions is exactly $\{x \mapsto x + c \mid c \ge 0\}$.
