# IMO 2026 Problem 4 - Solution

## Problem Restatement
Shan-Yu and Mulan play a game with a fixed angle θ (0° < θ < 180°). Shan-Yu chooses an initial triangle T. In each round:
1. If T has an angle exactly θ, Mulan wins.
2. Otherwise, Mulan chooses a point P on the perimeter of T (not a vertex) and cuts from P to the opposite vertex, splitting T into two triangles.
3. Shan-Yu discards one triangle; the other becomes the new T.

Determine all θ for which Mulan can guarantee victory in finitely many steps regardless of Shan-Yu's play.

## Answer
**Mulan can guarantee victory iff θ ≤ 90°.**

---

## Proof

### Notation and Game Reformulation
Let the triangle's angles be (A, B, C) with A+B+C = 180°, A,B,C > 0.
When Mulan splits angle C (by choosing a point on the opposite side), she picks β ∈ (0, C). The two resulting triangles have angle sets:
- S_A = (A, β, 180°−A−β)  [keeps angle A]
- S_B = (180°−B−β, B, β)  [keeps angle B]

Shan-Yu chooses S_A or S_B. Mulan wins if any angle equals θ.

---

### Part 1: Mulan wins for all θ ≤ 90°

#### Case θ < 60°
In any triangle, max(A,B,C) ≥ 60° > θ. Let C > θ. Mulan splits C with β = θ ∈ (0, C). Both S_A = (A, θ, 180°−A−θ) and S_B = (180°−B−θ, B, θ) contain θ. **Mulan wins in 1 move.**

#### Case θ = 60°
If triangle is equilateral (60°,60°,60°), Mulan wins immediately. Otherwise some angle > 60° = θ, reduce to previous case. **Mulan wins in ≤1 move.**

#### Case 60° < θ ≤ 90°
Shan-Yu can start with all angles < θ (e.g., equilateral 60°). Let state be (A,B,C) with A,B,C < θ. Note that θ ≤ 90° ⇒ 180°−θ ≥ 90° ≥ θ, so A,B,C < θ ≤ 180°−θ.

Mulan splits any angle, say C. Since A < 180°−θ and B < 180°−θ, we have:
- B+C = 180°−A > θ
- A+C = 180°−B > θ

Thus min(B+C−θ, A+C−θ) > 0. Mulan chooses β ∈ (0, min(C, B+C−θ, A+C−θ)).

Then:
- S_A has angle 180°−A−β ≥ θ
- S_B has angle 180°−B−β ≥ θ

If either equals θ exactly, Mulan wins immediately. If both > θ, whichever Shan-Yu chooses, the new triangle has an angle > θ. On the next turn, Mulan splits that angle with β = θ and wins. **Mulan wins in ≤2 moves.**

---

### Part 2: Shan-Yu defends for all θ > 90°

Let θ = 90° + ε with ε > 0. Shan-Yu maintains the invariant:
> All angles < θ, and at least two angles ≥ 180°−θ = 90°−ε.

**Initial triangle:** Choose (90°−ε, 90°−ε, 2ε). All angles < 90°+ε, two angles = 90°−ε ≥ 90°−ε.

**Maintenance:** Suppose state (A,B,C) satisfies the invariant, with A ≥ 90°−ε, B ≥ 90°−ε, C < θ.

- **If Mulan splits C** (the smallest angle): β ∈ (0, C). Both S_A = (A, β, 180°−A−β) and S_B = (180°−B−β, B, β) have all angles < θ because:
  - A < θ, B < θ, β < C < θ
  - 180°−A−β = B+C−β > B ≥ 90°−ε (since β < C)
  - 180°−B−β = A+C−β > A ≥ 90°−ε
  
  Both resulting triangles satisfy the invariant (two angles ≥ 90°−ε). Shan-Yu chooses arbitrarily.

- **If Mulan splits A or B** (a large angle): WLOG split A with γ ∈ (0, A). Options:
  - Keep B: (B, γ, 180°−B−γ)
  - Keep C: (180°−C−γ, C, γ)
  
  Shan-Yu chooses the option where all angles < θ. Such an option always exists because:
  - For Keep B: need 180°−B−γ < θ ⇔ γ > 180°−B−θ = A+C−θ. Since A ≥ 90°−ε and θ = 90°+ε, A+C−θ ≤ C−2ε < C. As γ varies in (0,A), Shan-Yu can pick γ > max(0, A+C−θ) if Mulan chooses poorly, but Shan-Yu chooses *after* Mulan picks γ. Actually, Shan-Yu picks which triangle to keep. For any γ, at least one of Keep B or Keep C yields all angles < θ:
    - Keep B valid if γ > A+C−θ
    - Keep C valid if γ > A+B−θ
    Since A+B−θ = 180°−C−θ < 0 (as C < θ), Keep C is always valid for any γ > 0. The triangle is (180°−C−γ, C, γ) with 180°−C−γ = A+B−γ > A ≥ 90°−ε (since γ < A). So invariant holds.

Thus Shan-Yu can maintain the invariant forever. Since all angles remain strictly between 90°−ε and 90°+ε, no angle ever equals θ = 90°+ε. **Mulan never wins.**

---

### Conclusion
Mulan has a winning strategy iff **θ ≤ 90°**.
