## Problem
Let $\mathbb{R}_{>0}$ be the set of positive real numbers. Determine all functions $f :\mathbb{R}_{>0}\to \mathbb{R}_{>0}$ such that

\[
\sqrt{\frac{x^2 + f(y)^2}{2}}\ge \frac{f(x) + y}{2} \ge \sqrt{xf(y)}
\]

for every $x,y\in\mathbb{R}_{>0}$.

## Approaches tried
1. Numerical brute-force search (power laws, linear, rational, piecewise); only $f(x)=x+c$ with $c\ge 0$ passed.
2. Squaring and factoring for $f(x)=x+g(x)$; discovered identity $A+B = 2(x-y-g(y))^2$ and $A-B = -2(g(x)-g(y))(g(x)+g(y)+2x+2y)$.
3. Substitution $x = f(y)$ in the original chain yields the functional equation $f(f(y)) = 2f(y) - y$, and also forces equality $A=B=0$ for all pairs $(x,y)$ with $x=f(y)$.
4. Using the derived inequality $A\ge 0$, $B\ge 0$, plus $A+B$ and $A-B$ identities, proved that $g$ must be constant.
5. The constant $c$ must be $\ge 0$ because $f(x)=x+c > 0$ for all $x>0$.

## Current best
**Answer:** $f(x) = x + c$ for some constant $c \ge 0$.

## Full proof

Let $f:\mathbb{R}_{>0}\to\mathbb{R}_{>0}$ satisfy for all $x,y>0$

\[
\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)} . \tag{1}
\]

All quantities are positive, so squaring preserves the inequalities:

\[
\frac{x^2 + f(y)^2}{2} \ge \frac{(f(x)+y)^2}{4} \ge x f(y). \tag{2}
\]

Multiply by 4:

\[
2x^2 + 2f(y)^2 \ge (f(x)+y)^2 \ge 4x f(y). \tag{3}
\]

---

### 1. A functional equation

In (3) take $x = f(y)$.  Since $f(y)>0$, this is a legitimate substitution.  Then:

\[
2f(y)^2 + 2f(y)^2 \ge \bigl(f(f(y)) + y\bigr)^2 \ge 4 f(y)\, f(y).
\]

The left and right sides both equal $4f(y)^2$.  Hence the whole chain collapses to equalities:

\[
\bigl(f(f(y)) + y\bigr)^2 = 4f(y)^2.
\]

Because all quantities are positive, we take square roots and obtain

\[
f(f(y)) + y = 2f(y) \quad\Longrightarrow\quad f(f(y)) = 2f(y) - y \qquad \forall y>0. \tag{4}
\]

Equivalently,
\[
\boxed{f(f(x)) = 2f(x) - x \qquad \forall x>0.}
\]

Moreover, the substitution $x = f(y)$ forced the two inequalities in (3) to be equalities for the pair $(f(y), y)$.  Thus for every $y>0$,

\[
(f(f(y)) + y)^2 = 4 f(y)^2 \quad\text{and}\quad 2f(y)^2 + 2f(y)^2 = (f(f(y))+y)^2,
\]
which are automatically satisfied by (4).  But also we have the original inequalities with $x$ and $y$ interchanged; the condition $A\ge 0$, $B\ge 0$ (defined below) become equalities when $x = f(y)$.

---

### 2. Rewriting with $g(x)=f(x)-x$

Define $g(x) = f(x) - x$ for all $x>0$.  Then $g(x) > -x$ (because $f(x)>0$).  Equation (4) becomes

\[
f(f(x)) = f(x+g(x)) = (x+g(x)) + g(x+g(x)) = 2(x+g(x)) - x,
\]
so
\[
x + g(x) + g(x+g(x)) = x + 2g(x),
\]
hence
\[
\boxed{g(x+g(x)) = g(x) \qquad \forall x>0.} \tag{5}
\]

Equation (5) is a characteristic functional equation: $g$ is invariant under adding $g(x)$ to $x$.

Now insert $f(x) = x+g(x)$ and $f(y) = y+g(y)$ into (3).  For brevity write $a = g(x)$ and $b = g(y)$.  Then (3) is

\[
2x^2 + 2(y+b)^2 \ge (x+y+a)^2 \ge 4x(y+b). \tag{6}
\]

Define

\[
\begin{aligned}
A(x,y) &:= 2x^2 + 2(y+b)^2 - (x+y+a)^2, \\
B(x,y) &:= (x+y+a)^2 - 4x(y+b).
\end{aligned}
\]

Both are $\ge 0$ for all $x,y>0$.

---

### 3. Two algebraic identities

A direct expansion (or using computer algebra) gives

\[
\begin{aligned}
A(x,y) &= (x-y)^2 - a^2 - 2a(x+y) + 4by + 2b^2, \\
B(x,y) &= (x-y)^2 + a^2 + 2a(x+y) - 4bx.
\end{aligned}
\]

From these we compute

\[
\begin{aligned}
A+B &= 2x^2 - 4x(b+y) + 2(b+y)^2 = 2\bigl(x - y - b\bigr)^2, \tag{7}\\
A-B &= -2a^2 - 4a(x+y) + 4b^2 + 4by + 4bx \\
    &= -2(a^2 + 2a(x+y) - 2b^2 - 2b(x+y)) \\
    &= -2(a-b)\bigl(a + b + 2x + 2y\bigr). \tag{8}
\end{aligned}
\]

The identity (7) is particularly powerful: because $A,B \ge 0$, their sum is

\[
A(x,y) + B(x,y) = 2\bigl(x - y - g(y)\bigr)^2.
\]

Thus $A+B$ is exactly twice a square; it does **not** depend on $g(x)$ at all.

---

### 4. Bounding $g(x)$ from below

Since $A(x,y) \ge 0$ and $B(x,y) \ge 0$, we have

\[
0 \le A(x,y) \le A(x,y) + B(x,y) = 2\bigl(x - y - g(y)\bigr)^2.
\]

Wait — $A \ge 0$ and $B \ge 0$ implies $0 \le A \le A+B$, but $A\le A+B$ is always true because $B\ge 0$.  More usefully, we also have $0 \le B \le A+B$.

Thus
\[
0 \le B(x,y) \le 2\bigl(x - y - g(y)\bigr)^2. \tag{9}
\]

Now fix $y$ and consider $x = y + g(y)$.  Then $x - y - g(y) = 0$, so $A+B = 0$.  Since $A,B \ge 0$, we must have $A = B = 0$ for this particular pair.

Let's check: $x = y + g(y) = f(y)$.  Indeed we already proved that for $x = f(y)$ the two inequalities become equalities (see §1).  So this is consistent.

Now, from $B(x,y) \ge 0$ for all $x$, we substitute the expression of $B$:

\[
B(x,y) = (x-y)^2 + a^2 + 2a(x+y) - 4bx \ge 0.
\]

Rewrite as a quadratic in $a$ (where $a = g(x)$):

\[
a^2 + 2a(x+y) + (x-y)^2 - 4bx \ge 0.
\]

Complete the square in $a$:

\[
(a + x + y)^2 - (x+y)^2 + (x-y)^2 - 4bx \ge 0.
\]

Since $(x+y)^2 - (x-y)^2 = 4xy$, we obtain

\[
(a + x + y)^2 \ge 4xy + 4bx = 4x(y+b) = 4x f(y). \tag{10}
\]

Taking square roots (all positive):

\[
a + x + y \ge 2\sqrt{x f(y)},\qquad\text{or}\qquad a + x + y \le -2\sqrt{x f(y)}.
\]

The second case is impossible since $a = g(x) > -x$, so $a+x+y > y > 0$.  Hence

\[
g(x) + x + y \ge 2\sqrt{x f(y)}.
\]

But this is exactly the inequality we started with (the left side is $f(x)+y$).  So nothing new.

---

### 5. Proving $g$ is constant

We now use the identity (7) in a clever way.  Since $A \ge 0$ and $B \ge 0$, we have

\[
A(x,y)\, B(x,y) \ge 0.
\]

But more importantly, from $A+B = 2(x-y-b)^2$ we get, for any $x$,

\[
B(x,y) \le A(x,y) + B(x,y) = 2(x-y-b)^2.
\]

Thus

\[
0 \le B(x,y) \le 2\bigl(x - y - g(y)\bigr)^2. \tag{11}
\]

Now fix an arbitrary $x_0 > 0$ and consider the inequality (11) with $y$ chosen such that $x_0 - y - g(y) = 0$, i.e., $y$ satisfies $y + g(y) = x_0$, which means $f(y) = x_0$.  Does such $y$ always exist?  Not necessarily for arbitrary $x_0$; we only know $f$ maps $\mathbb{R}_{>0}$ into itself.  We cannot assume surjectivity.

Instead, we use a different tactic.  Let us express $A$ and $B$ symmetrically.

From (7):
\[
A(x,y) + B(x,y) = 2(x - y - b)^2.
\]
Interchanging $x$ and $y$,
\[
A(y,x) + B(y,x) = 2(y - x - a)^2 = 2(x + a - y)^2.
\]

But $A(y,x) = B(x,y)$?  Let's check:
\[
A(y,x) = 2y^2 + 2(x+a)^2 - (y+x+b)^2,
\]
while
\[
B(x,y) = (x+y+a)^2 - 4x(y+b).
\]
These are not obviously equal.  However, we can compute $A(y,x)$ explicitly:

\[
A(y,x) = 2y^2 + 2(x+a)^2 - (x+y+b)^2.
\]

Now, $A(x,y)$, $B(x,y)$, $A(y,x)$, $B(y,x)$ are four nonnegative quantities.  Their pairwise sums give relationships.

Let's compute $A(x,y) + A(y,x)$:
\[
A(x,y) + A(y,x) = \bigl[2x^2 + 2(y+b)^2 - (x+y+a)^2\bigr] + \bigl[2y^2 + 2(x+a)^2 - (x+y+b)^2\bigr].
\]

But there is a simpler path.  The identity (7) says

\[
A(x,y) + B(x,y) = 2\bigl(x - f(y)\bigr)^2.
\]

Thus $A+B$ depends only on $x$ and $f(y)$, not on $f(x)$.  By symmetry, we also have

\[
A(y,x) + B(y,x) = 2\bigl(y - f(x)\bigr)^2.
\]

Now, note that $A(x,y)$ and $B(y,x)$ both involve $a = g(x)$ and $b = g(y)$.  Let's compute $A(x,y) + B(y,x)$:

\[
\begin{aligned}
A(x,y) + B(y,x) &= \bigl[2x^2 + 2(y+b)^2 - (x+y+a)^2\bigr] + \bigl[(y+x+b)^2 - 4y(x+a)\bigr] \\
&= 2x^2 + 2(y+b)^2 - (x+y+a)^2 + (x+y+b)^2 - 4y(x+a).
\end{aligned}
\]

But $(x+y+b)^2 - (x+y+a)^2 = (b-a)(2x+2y+a+b)$.  So

\[
A(x,y) + B(y,x) = 2x^2 + 2(y+b)^2 + (b-a)(2x+2y+a+b) - 4y(x+a).
\]

This seems messy.  Let's use sympy to find a clean factorization.

Actually, we have already found in earlier exploration:

\[
A - B = -2(a-b)(a+b+2x+2y).
\]

This is key!  Since $A \ge 0$ and $B \ge 0$, we have $|A-B| \le A+B$.  Actually, from $A,B\ge 0$, we can only say $-B \le A-B \le A$.  But we also have $A+B$ known.

Consider the following: fix $x$ and $y$ and look at the two numbers $A$ and $B$.  They satisfy

\[
\begin{aligned}
A + B &= 2(x - y - b)^2, \\
A - B &= -2(a - b)(a + b + 2x + 2y).
\end{aligned}
\]

Solving for $A$ and $B$:

\[
A = (x - y - b)^2 - (a - b)(a + b + 2x + 2y),
\]
\[
B = (x - y - b)^2 + (a - b)(a + b + 2x + 2y).
\]

Since $A,B \ge 0$, we obtain

\[
\begin{aligned}
(x - y - b)^2 &\ge (a - b)(a + b + 2x + 2y), \\
(x - y - b)^2 &\ge -(a - b)(a + b + 2x + 2y).
\end{aligned}
\]

These two together imply

\[
\bigl| (a - b)(a + b + 2x + 2y) \bigr| \le (x - y - b)^2. \tag{12}
\]

Inequality (12) must hold for **all** $x,y > 0$.

Now, notice that the right side $(x - y - b)^2$ involves $b = g(y)$ but does **not** involve $a = g(x)$.  The left side is proportional to $|a - b|$ (times a positive factor).

### 6. A strategic choice of variables

Fix an arbitrary $y_0 > 0$ and let $b_0 = g(y_0)$.  Choose $x$ such that $x - y_0 - b_0 = 0$, i.e., $x = y_0 + b_0 = f(y_0)$.  Then the right side of (12) is zero, forcing the left side to be zero as well:

\[
(a - b_0)\,(a + b_0 + 2f(y_0) + 2y_0) = 0.
\]

Since $a + b_0 + 2f(y_0) + 2y_0 > 0$ (all terms positive because $a = g(x) > -x$ and $x = f(y_0) > 0$, but let's verify: $a + b_0 + 2x + 2y_0 = g(f(y_0)) + g(y_0) + 2f(y_0) + 2y_0$.  From the functional equation (5), $g(f(y_0)) = g(y_0 + g(y_0)) = g(y_0) = b_0$.  So $a = b_0$.  Then $a + b_0 + 2x + 2y_0 = 2b_0 + 2(y_0+b_0) + 2y_0 = 4b_0 + 4y_0 > 0$.)

Thus the factor $(a + b_0 + 2x + 2y_0)$ is strictly positive.  Hence $a - b_0 = 0$, i.e., $g(f(y_0)) = g(y_0)$.  This we already knew from (5).  It doesn't force $g$ to be globally constant.

We need a different choice of $x,y$ to extract more information.

### 7. Using the inequality $A \ge 0$ directly

Recall

\[
A(x,y) = 2x^2 + 2(y+b)^2 - (x+y+a)^2 \ge 0.
\]

Treat this as a quadratic inequality in $a = g(x)$.  Since the term $-a^2$ appears, it is concave in $a$.  Complete the square:

\[
\begin{aligned}
A &= 2x^2 + 2(y+b)^2 - (x+y)^2 - 2a(x+y) - a^2 \\
  &= \bigl[2x^2 + 2(y+b)^2 - (x+y)^2\bigr] - a^2 - 2a(x+y).
\end{aligned}
\]

Let $C(x,y) = 2x^2 + 2(y+b)^2 - (x+y)^2$.  Then

\[
A = C - a^2 - 2a(x+y) = C + (x+y)^2 - (a + x + y)^2.
\]

Because $C + (x+y)^2 = 2x^2 + 2(y+b)^2$.  So

\[
A = 2x^2 + 2(y+b)^2 - (a + x + y)^2.
\]

But $a + x + y = f(x) + y$.  So this is just the original form.  Not helpful.

Let's instead use the symmetry between the two inequalities.  We have

\[
A(x,y) \ge 0,\quad B(x,y) \ge 0,
\]
and also
\[
A(y,x) \ge 0,\quad B(y,x) \ge 0.
\]

We can take linear combinations.  Consider $A(x,y) + A(y,x) \ge 0$:

\[
\begin{aligned}
&A(x,y) + A(y,x) \\
&= \bigl[2x^2 + 2(y+b)^2 - (x+y+a)^2\bigr] + \bigl[2y^2 + 2(x+a)^2 - (x+y+b)^2\bigr] \\
&= 2x^2 + 2y^2 + 2(y+b)^2 + 2(x+a)^2 - (x+y+a)^2 - (x+y+b)^2.
\end{aligned}
\]
